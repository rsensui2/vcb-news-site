タイトル: Claude Codeを活用したプレゼン資料の具体的作り方5ステップ

AIでプレゼン資料を作っているなら、PowerPointやGoogleスライドを使っている時点で、その実力の半分も引き出せていません。

テンプレートを選ぶ。

テキストを流し込む。

レイアウトを微調整する。

これは従来の作業をAIで少し効率化しただけです。

AIにしかできないプレゼンの作り方は、まったく別のところにあります。

なぜ「普通の使い方」ではAIプレゼンの価値を引き出せないのか？

PowerPointやGoogleスライドの枠組みの中でAIを使う限り、出力はそのツール自体の制約に縛られます。アニメーション付きの図表、動的に変化するグラフ、モダンで自由度の高いレイアウトはスライドツールでは実現できない。

AIプレゼン作成——本当の強みは2つ：

  1. コードによる出力 — AIにHTMLでプレゼンを生成させれば、アニメーション付きグラフや動的な図表、自由なビジュアル表現が手に入る
  2. コード生成がAIの最も得意な領域 — テキスト・画像生成と比較しても、コードの生成精度は群を抜いている

5ステップ

  1. スクリプトの準備 — AIが視覚化するための「参照元」（台本 or アウトライン）を用意。論理的な流れと構造が重要。「考える作業」と「デザイン作業」を分業
  2. Claudeプロジェクト作成 — Instructions欄にシステムプロンプト設定。ファイル形式（単一HTML、CSS/JSインライン）、テキスト量（スライドあたり最大3行）、色設計（ダークグラデーション+アクセントカラー）、ビジュアル優先、アニメーション、操作性（キーボード矢印）を含める。Knowledge欄に過去の気に入ったHTMLをアップして参照
  3. チャット内編集（2回まで） — 5〜6個の変更をまとめて一括投入。3回目以降はコンテキスト汚染で品質劣化
  4. Claude Codeで仕上げ編集 — npm install -g @anthropic-ai/claude-code → ローカルでファイル直接編集、自然言語で「スライド3の色を#00D4FFに」など。構造変更はチャット、細部はClaude Codeで使い分け
  5. GitHub Pagesでデプロイ — ファイル名 index.html、リポジトリのルート配置、Settings → Pages → mainブランチをSave。2〜5分でURL発行

まとめ

Claude Code 時代のプレゼン資料作成ワークフロー記事の告知ポスト。「PowerPoint/Googleスライドの枠を捨て、HTML+Claude Code でコード出力としてプレゼンを生成すべき」という主張を5ステップに整理。スクリプト準備 → Claudeプロジェクト → チャット編集（2回まで） → Claude Code仕上げ → GitHub Pagesデプロイ、の流れ。
