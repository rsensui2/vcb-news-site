X Article 本文

ClaudeOpus4.8がリリース！更に『Dynamic Workflow』の新機能など

まず 結論から言うと、Opus 4.8 は「同じ料金で賢くなった Opus 4.7」。

コーディング・自律タスク・専門知識作業の全方位で benchmark が上がり、長時間回り続ける仕事 (= long-running、夜通しの移行作業のような長丁場) を最後までやり切る一貫性が増した。

公式も、控えめだが確かな改善と言い切っている。

今回新しくなったのは ① effort control (Claude にどれだけ考えさせるか選べる) ② dynamic workflows (数百のサブエージェントを並列で走らせる) ③ fast mode (2.5 倍速モードが従来の 3 分の 1 の価格に)

前世代 Opus 4.7 を全項目で上回る。たとえば実務寄りのコーディング (SWE-Bench Pro) は 64.3% から 69.2% へ、知識作業の総合スコア (GDPval-AA) は 1753 から 1890 へ伸びた。

一番の進化は「正直さ」

AI の一番こわい失敗は「嘘の進捗報告」。証拠が薄いのに自信ありげに「直しました」と言い切るこの癖を 4.8 は明確に減らした。公式の評価では、自分が書いたコードの欠陥を見逃して素通りさせる確率が、前世代の約 4 分の 1 になった。不確実なところには自分から旗を立て、断定を避けるようになっている。

安全性の事前評価でも、人をだます・悪用に手を貸すといった誤った振る舞いが 4.7 より大幅に少なく、最も整った社内モデル (Claude Mythos Preview) に並ぶ水準だった。

Dynamic workflows

計画する — 大仕事を小タスクへ自分で分解する。

並列で走らせる — 数百のサブエージェントが同時に処理する (4.8 ではより長く回り続けられる)。

自分で検証する — 結果をまとめる前に出力を点検する。

報告する — 検証を通ったものだけを人に返す。

Claude Code の新機能 dynamic workflows は、これまで人が手で分割していた大仕事を Claude 自身に任せる仕組み。例えば deep-research コマンドも登場している。

effort control

「Claude にどれだけ考えさせるか」を選ぶつまみ。claude.ai と Cowork でモデル選択の隣に現れ、全プランで使える。default は high で、品質と体感のいちばん良いバランス。コーディングでは Opus 4.7 の default とほぼ同じトークン量で性能だけ上がる。

開発者向けには Messages API がやり取りの途中に system エントリを差し込めるようになり、prompt cache を壊さず権限・トークン予算・環境の前提を途中更新できる。

価格

Opus 4.7 から据え置き。fast mode は 2.5 倍速で従来モデルの 3 分の 1 の価格。

筆者の感想（要約）

メタ認知能力が高く、今までと問題解決の思考が違う。議論が強く、token は溶けるのでコスパは別問題。opus が好きだった人がさらに好きになる印象。
