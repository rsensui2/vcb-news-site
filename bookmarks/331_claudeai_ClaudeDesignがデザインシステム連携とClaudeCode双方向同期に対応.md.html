Claude Design がデザインシステム連携と Claude Code 双方向同期に対応

№068 / 470 SRCx.com/claudeai ↗ GHGitHub ↗
068BOOKMARK / 470

有益度: ⭐⭐⭐⭐

エンゲージメント: Likes 4900 / RT 304 / Bookmarks 1864 / Views 279,853

概要

Claude Design のアップデート発表。プロジェクトを跨いで自社のデザインシステム（ブランド）に沿った生成を維持し、キャンバス上で直接編集でき、Claude Code と双方向同期し、既存ツールとの連携も拡張された。全有料プランで web / desktop のベータとして提供。

まとめ

  • リポジトリ・デザインファイル・コードベースからデザインシステムをインポートでき、Claude が実コンポーネントでビルドし、出力をユーザーに見せる前に自身でデザインシステムと照合する。
  • Claude Design と Claude Code が双方向連携（本日ロールアウト）。デザインをビルドへ引き渡すことも、Claude Code から始めてターミナル経由でデザインプロジェクトを同期することもできる。
  • PDF / PowerPoint へのエクスポート、他ツールへの送出に対応。
  • 再設計されたエディタは日常作業向けに安定性が向上。新しいレイアウトコントロールでキャンバス上の要素をドラッグ・リサイズ・整列できる。

スレッド全体

Part 1 (親ポスト)

New in Claude Design: it stays on brand with your design system across projects, lets you edit directly on the canvas, syncs with Claude Code, and connects to more of the tools you already use.

Part 2

Import your design system from a repo, design files, or your codebase. Claude builds with your real components and checks its own output against your design system before you see it.

Part 3

The redesigned editor is steadier for daily work. New layout controls let you drag, resize, and align elements directly on the canvas.

Part 4

Claude Design and Claude Code work together in both directions (rolling out today). Hand a design off to build, or start in Claude Code and sync design projects from your terminal. Export to PDF and PowerPoint, or send your work to more of the tools you already use.

Part 5

Claude Design is in beta on all paid plans, on web and desktop. Give it a try.
