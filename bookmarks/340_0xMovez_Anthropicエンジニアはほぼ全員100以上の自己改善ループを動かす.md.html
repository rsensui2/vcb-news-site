概要

Claude Code の生みの親 Boris Cherny が約1時間のポッドキャストで語った内容の紹介ポスト。要点は「Anthropic ではエンジニアのほぼ100%が、自己改善ループを備えた100体以上のエージェントを走らせている」「self-improving loop はエージェントを毎回の実行で賢くする」というもの。Boris はエージェントループをゼロからどう組むかを解説し、"Claude + loops + routines + dynamic workflows" が秘訣だと位置づける。

まとめ

  • Anthropic 社内ではエンジニアのほぼ全員が 100 体以上のエージェントを、自己改善ループ付きで日常的に運用していると主張。
  • self-improving loop = 実行のたびに学びを蓄積し、次の実行をより良くする仕組み。
  • 鍵となる4要素として Claude / loops / routines / dynamic workflows を挙げる。
  • 1時間のトークでループの組み方を最初から解説（その後、同じ playbook をクオンツ取引に応用する流れに接続）。

原文（日本語訳）

Claude Code の生みの親：「Anthropic では、エンジニアのほぼ100%が、自己改善ループを備えた100体以上のエージェントを動かしている。自己改善ループは、実行のたびにエージェントを賢くする」。1時間のポッドキャストで、Boris はエージェントループをゼロからどう構築するかを解説している。Claude＋loops＋routines＋dynamic workflows——それが秘訣だ。
