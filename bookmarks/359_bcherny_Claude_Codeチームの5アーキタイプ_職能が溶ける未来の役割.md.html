Boris Cherny、Claude Code チームの「5つのアーキタイプ」を提示 — 職能が溶ける未来の役割像

概要

Claude Code の作者 Boris Cherny が、エンジニアリング・プロダクト・デザイン・DS などの職能が「新しい役割」へ溶け合っていく未来を考察。Claude Code チームを観察して見えた5つのアーキタイプを提示し、プロダクトのフェーズごとに必要なミックスが変わると論じる。

まとめ

  • 5つのアーキタイプ：

1. Prototyper: 全く新しいアイデアを大量に生み、ほとんどは出荷されない

2. Builder: プロトタイプ/アイデアを素早く production グレードの製品/インフラに

3. Sweeper: UI を整え、コードとシステムを簡素化し、不要機能を削り、性能を最適化

4. Grower: 作られた製品を磨き込み PMF を改善

5. Maintainer: 成熟システムを所有し、スケールしても安全・信頼・高速・効率を保つ

  • 多くの人は2つ（時に3つ）の役割をまたぐ。これらは職種（job function）に縛られない——デザイナーにもタイプ1も2も3もいるし、エンジニア・PM・DS も同様。
  • プロダクトのフェーズで必要なミックスが変わる：

- 新規・PMF前 → 1+2+3 が強い人

- 成長中・PMF達成 → 2+3+4 と一部の5

- 強い PMF → 3+4+5 と一部の2

  • 未来のプロダクト役割は、今日の職能特化型ではなく、このアーキタイプ型に近づくかもしれない。
