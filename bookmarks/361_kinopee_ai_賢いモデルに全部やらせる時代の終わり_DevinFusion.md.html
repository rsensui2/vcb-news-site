「賢いモデルに全部やらせる」時代の終わり — Cognition の Devin Fusion を読み解く

№093 / 516 SRCx.com/kinopee_ai ↗ GHGitHub ↗
093BOOKMARK / 516

有益度: ⭐⭐⭐⭐

エンゲージメント: Likes 110 / RT 10 / Replies 0 / Bookmarks 170 / Views 80,109

概要

Cognition が「Devin Fusion」を発表。賢く高いモデルと安いモデルを組み合わせ、性能はそのままにコストを 35% 下げた話。読みどころは「混ぜたこと」自体ではなく「どこに線を引いて設計したか」。

まとめ

  • sidekick(相棒)方式: 賢いメインと安い相棒を2体同時に走らせる。相棒は「言われたことだけやる下請け」ではなく、自分でツールを使い情報を集める一人前のエージェント。メインは「計画」「曖昧な指示の読み取り」「最終チェック」だけを担い、手は動かさず指揮者に徹する。
  • キャッシュを設計の主役に: 従来の「賢いモデルが別モデルに相談する」型（自社 Smart Friend や Anthropic の Advisor）は相談のたびに文脈を渡し直してキャッシュが切れ高くつく。Fusion は両者が自分のキャッシュを保持したまま並走するので連携しても余計なコストが出ない。「相談しに行く」から「最初から並んで走らせる」への転換。
  • 乗り換えをタダにする小ワザ: モデル切替はキャッシュが切れて高くつくが、Fusion は「文脈の圧縮（どのみちキャッシュが切れる瞬間）」に乗り換えを合わせ、実質タダにする。お金の側から逆算する発想。
  • 任せていい線引き: テスト実行や OpenTracing 一括削除など「判断は済んで作業量だけ」のタスクは任せて 32〜62% 安く品質維持。一方「検索バーにチーム選択機能を足す」など判断そのものが成果物のタスクは任せるとスコア半減。「判断そのものが成果物なら任せると裏目に出る」。
  • 数字: Fusion は GPT-5.5 / Opus 4.8 比でコスト 35% 減・性能同等。Fusion + Fable 5 は Fable 5 単独比で 41% 減（※Fable 5 は米政府指令で 6/12 アクセス停止、数字は停止前測定）。社内でマージされた PR の 88% が Fusion の自動振り分けだけで処理された。
