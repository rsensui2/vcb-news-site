概要

Claude の見落とされがちな機能を「どこにあるか・どうオンにするか・すぐ使えるプロンプト」付きで17個まとめた実用ガイド記事。各機能は数分で設定でき、以後毎日効いてくる、という触れ込み。通常の Claude に隠れた機能、ロールを与えるプロンプト集、そしてプロダクト機能（Chrome/Cowork/Claude Code/Design 等）の3ブロック構成。

まとめ

通常 Claude の隠れ機能:

  1. Projects — ドキュメントと常設指示を永続保持。毎回自己紹介し直す必要がなくなる。まず最初にやるべき設定。
  2. Artifacts — チャット内で実際に動くアプリ（電卓・習慣トラッカー・ゲーム・チャート付きダッシュボード）を横パネルに生成。SVG/インタラクティブチャート/Mermaid 対応、無料プランでも使える。
  3. Adaptive/Extended Thinking — 回答前に段階的推論を行い、その過程を見られるモード。複雑な意思決定・戦略分析で差が出る。
  4. Memory — 時間をかけてユーザーのプロフィール（職業・プロジェクト・コミュニケーション好み）を構築。新規チャットでも文脈を把握。デフォルト off。

ロールを与えるプロンプト集（新規チャット冒頭に貼る）:

  1. パーソナル心理士（CBT セラピスト風・答えでなく問いを返す）
  2. 厳しいメンター（同意をやめ弱い前提を潰すストレステスト役）
  3. パーソナルトレーナー（実数値からテンプレでない運動計画）
  4. 難しい会話の練習（相手役をリアルに演じ、弱い主張には反論）
  5. 悪魔の代弁者（決断に対し、現実的な失敗3パターンを突きつける）

知られていないプロダクト機能:

  1. Claude in Chrome — アクティブタブを見て操作（リンククリック・フォーム入力・遷移）できる拡張。
  2. Claude Cowork — デスクトップアプリ。ファイルシステムに直接アクセスして読み書き・整理。
  3. Scheduled Tasks — 一度設定すれば指定時刻・頻度で自動実行しフォルダに出力。
  4. Skills in Cowork — プラグインのように能力を追加インストール（PowerPoint/PDF/特定ワークフロー）。
  5. CLAUDE.md — プロジェクトフォルダに置くと毎セッション自動で読む規約ファイル。
  6. Claude Code — ターミナルで動き、コードベースを読んでコード生成・テスト・バグ修正をループで回す。VS Code/JetBrains/GitHub Actions 統合。
  7. Claude Design — 資料・ピッチデック・プロトタイプ・LP を作る visual ツール。PPTX/Canva/PDF/HTML 書き出し。claude.ai/design。
  8. Prompt Caching（開発者向け） — 繰り返す大きなコンテキストをサーバ側にキャッシュしてトークンコスト最大90%削減。"cache_control": {"type": "ephemeral"} を付与、5分保持。

締め: 「1つだけ選んで今日設定せよ。全部一度にやる必要はない、何が存在するか知っているだけで半分勝ち」。

日本語訳全文

タイトル: Claude はこれ全部できる。ほとんどの人は知らない。

Claude はほとんどの人が思うよりずっと多くのことができる。このガイドはその全部を扱う — 各機能がどこにあるか、どうオンにするか、すぐ使えるプロンプト付きで。目を通し、自分のワークフローに合うものを選び、今日設定しよう。どれも数分で設定でき、その後は毎日効いてくる。

通常の Claude に隠れた機能

  1. Projects — あなたを本当に覚えている Claude。新しいチャットを開くたび Claude はゼロから始まり、あなたの名前も仕事も好みも知らない。Projects はこれを直す。プロジェクトを作り、ドキュメントをアップロードし、常設指示を書けば、Claude はそれを恒久的に保持する。何より先に直すべき最初の項目。
  2. Artifacts — チャット内で動く実物アプリ。Claude はテキストしか出せない、というのは誤り。Artifacts はチャット内の横パネルで実際に動くもの（電卓・習慣トラッカー・ゲーム・チャート付きダッシュボード）を作る。SVG・インタラクティブチャート・Mermaid 図に対応。無料プランで使える。
  3. Adaptive/Extended Thinking — 別次元の推論。多くのユーザーがオンにしたことがない。回答前に段階的に推論し、その過程をすべて見られるモード。単純な質問には不要だが、複雑な意思決定・戦略分析では出力の差が大きい。
  4. Memory — あなたが誰かを知っている Claude。オンにすると Claude は時間をかけてあなたのプロフィール（仕事・プロジェクト・コミュニケーションの好み・今取り組んでいること）を作る。デフォルトでオフ。

Claude に役割を与える — ひとつのプロンプトがすべてを変える

  1. パーソナル心理士 — 答えでなく問いを返し、あなたの考えを検証（CBT セラピスト風）。
  2. 厳しいメンター — 同意をやめ、弱い前提・見落とし・計画が壊れる箇所をストレステストする。
  3. パーソナルトレーナー — あなたの実数値から本物の計画を作る。テンプレではない。
  4. 難しい会話の練習 — Claude が相手役をリアルに演じ、弱い主張には反論する。
  5. 悪魔の代弁者 — 決断に対し、丁寧な懸念でなく全面的な反証と現実的な失敗3パターンを突きつける。コミット前の5分を。

ほとんどの人が存在を知らないプロダクト機能

  1. Claude in Chrome — あなたが見ているものを見る Claude。アクティブタブを読み、リンクをクリックし、フォームを入力し、URL へ遷移する拡張。Chrome ウェブストアで「Claude for Chrome」を検索→インストール→サインイン。
  2. Claude Cowork — デスクトップに住む Claude。ファイルシステムに直接アクセスし、実ファイルを読み・編集し・新規作成し・フォルダを整理する。
  3. Scheduled Tasks — あなたが寝ている間に働く Claude。一度タスクを設定すれば、選んだ時刻・頻度で自動実行し、出力をフォルダに保存する。
  4. Skills in Cowork — プラグインのように新しい能力をインストール。一度スキルを入れれば、その種のタスク（PowerPoint 作成・PDF 操作・特定ワークフロー）を Claude が既に知っている。スマホのアプリのようなもの。
  5. CLAUDE.md — 毎セッション Claude が自動で読む規約。Cowork と Claude Code で、プロジェクトフォルダに CLAUDE.md を作れば、Claude は毎回のセッション冒頭で頼まずとも読む。コーディング規約・文体ルール・社内用語・ブランドボイスを一度書けば、そのプロジェクトの全セッションで永続的に従う。
  6. Claude Code — ターミナルでコードを書き・テストし・修正する AI。スニペットだけでなく、本番級のコード・機能全体・複雑なリファクタまで。実際のコードベースを読み、新しいコードを書き、テストを走らせ、エラーメッセージを読み、タスク完了までループでバグを直す。VS Code・JetBrains と統合、GitHub Actions にも組み込める。
  7. Claude Design — ビジュアル作業のための AI。製品ワンページャー・ピッチデック・プロトタイプ・LP レイアウト。必要なものを説明すれば Claude が作り、PPTX・Canva・PDF・HTML に書き出す。デザイナーでない人にとって、3時間の Figma 作業を10分の会話に置き換える。claude.ai/design が直リンク。
  8. Prompt Caching（開発者向け）— API 呼び出しのコスト90%削減。大きな繰り返しコンテキスト（長いシステムプロンプト・参照文書・コードベース）を含むリクエストでは、毎回同じトークンを再処理する料金を払っている。Prompt Caching はその内容をサーバ側に保存し、以降の呼び出しは再処理せずキャッシュを再利用する。キャッシュしたいコンテンツブロックに "cache_control": {"type": "ephemeral"} を付ける。キャッシュは5分保持され、使うたびタイマーがリセットされる。

これであなたは、毎日使っているほとんどの人より Claude に詳しくなった。このリストから機能を1つだけ選んで、今日設定しよう。一度に全部やる必要はない。何が存在するか知っているだけで、もう半分は勝ちだ。
