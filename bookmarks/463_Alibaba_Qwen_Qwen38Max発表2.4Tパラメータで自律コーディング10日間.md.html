概要

Alibaba の Qwen チームが最上位モデル Qwen3.8-Max を公開。2.4T（2兆4千億）パラメータで、売りは「コーディング」と "cowork"（実務の代行）の2本立て。

最大の目玉は 来週のオープンウェイト公開。Max 級のフラッグシップを重み付きで出すのは異例で、加えて Qwen3.8-27B もオープンウェイト化される。27B ならローカル運用の現実的な射程に入る。

まとめ

  • 2.4T パラメータ。コーディングと cowork（複数職種の実務遂行）に照準
  • Autonomous coding: 10日超。空フォルダから本番投入可能なものまで、人の手当てなしで自己進化的に開発。全トレースを GitHub (qwen-code-dev-bot/oh-my-cli) で公開している
  • Long-horizon: チップ設計最適化で 500+ ターン、EC戦略で 365日相当の閉ループ計画・適応学習を回したと主張
  • ネイティブマルチモーダル: 視覚を「入力」ではなく計画・実行・自己修正の継続的フィードバックループとして扱う
  • 価格: Input $2.0 / M tokens、Output $6.0 / M tokens、Implicit Caching $0.25 / M tokens
  • 来週オープンウェイト公開: Qwen3.8-Max と Qwen3.8-27B
