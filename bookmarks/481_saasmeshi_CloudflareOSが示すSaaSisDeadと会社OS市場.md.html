Cloudflare OS が示す「SaaS is Dead」— 完成品SaaSから会社OSの部品へ

投稿本文（原文）

気づいてるか？

AI時代において最も勢いのあるレンタルサーバー会社『Cloudflare』がオープンソースOSをリリースしたことが話題だが、

このニュースの核心は「社内でAIを安全に使えるようになった」ではなくて、SaaS is Deadがようやく現実味を帯びていき会社用OSが台頭するという未来が示されたことだ。その理由と新たなビジネスチャンスについて解説する。Cloudflareを知らない人のために言えば、ざっくり「企業のサイトやアプリを置き、速くし、攻撃から守る会社」だ。そのCloudflareが公開したCloudflare OSは、WindowsやMacのようなパソコン用OSではない。社員がブラウザ上でAIに仕事を頼み、社内資料や業務システムを使わせ、資料だけでなく小さな業務アプリや自動化まで作らせるための"会社用の仕事場"だ。オープンソースなので、設計図が公開され、各社が自社仕様に改造できる。なお、公開されたv2はまだ初期提供版で、荒い部分も残る。Cloudflare社内では毎週数千人が使い、直近30日で4000以上のアプリやツールが作られたという。

これまで会社は、営業管理、経費精算、顧客対応、分析など、仕事ごとに完成品のSaaSを契約してきた。だがCloudflare OSでは、社員が「昨日の問い合わせを分類して、対応漏れを知らせる画面を作って」と頼めば、その人に必要なアプリをAIがその場で作る。足りない機能も会話で追加できる。つまり、全員が同じ既製品を我慢して使うのではなく、会社OSの上で、一人ひとりが必要なソフトを必要な時に生み出す。

これがSaaS is Deadの正体だ。SaaSが全部消えるわけではない。消えやすいのは、固定された管理画面や細かな便利機能だ。逆に、顧客台帳、決済、会計、契約、在庫のような「正しい記録」と、それを安全に操作するAPI、認証、権限管理は残る。将来はSaaSを人間が直接操作するのではなく、会社OSが複数のSaaSを裏側で動かし、必要な画面だけをAIが必要に応じて作る。SaaSは完成品から、会社OSが使う部品へ変わる。

ここに新しい市場が生まれる。

では、どう張るか。新しいビジネスチャンスは3つある。

第一は、日本企業向けの「会社OS導入業」だ。freee、kintone、SmartHR、LINE WORKSなどをAIへ安全につなぎ、誰が何を見て何を実行できるかを設計する。すでに日本のJiteraは、Microsoft TeamsやBoxなど1,000以上の外部アプリとAIをつなぎ、接続と認証を一元管理するMCP連携機能を提供している。

第二は、社内の散らばった資料や暗黙のルールを整理し、AIが使える正本へ変える「会社の文脈整備業」だ。米国のGleanは、100超のデータ源をつないで元の閲覧権限を保ったまま会社別の知識グラフを作る。導入企業Upsideでは全社展開まで1カ月、利用率92%、月2000時間超を削減したという。

第三は、社員が大量に作るAIアプリを登録し、費用、権限、責任者、最終利用日、事故時の停止方法まで管理する「AIアプリ管理業」だ。先行例はドイツSAPの『AI Agent Hub』だ。SAP製・他社製のAIエージェント、LLM、MCPサーバーを発見・台帳化・統制・評価し、すでに150社で10万超を管理している。

料金体系も変わる。私は今後、人間一人につき月額いくらではなく、AIが何件処理し、どのデータを読み、何回取引を実行したかで課金する「エージェント従量課金」が広がると見ている。会社OSを握る企業は、社内のあらゆるAI作業が通る料金所になれる。

最も大きいのは、会社がソフトを買う市場から、会社そのものをソフトウェア化する市場への転換だ。安くなるのは画面、コード、アプリ、知能だ。逆に希少になるのは、正しい社内データ、接続許可、操作権限、監査記録、責任の所在になる。だから次に一発当てる会社は、もう一つ便利なSaaSを作る会社ではなく、無数のAIと即席アプリが安全に働ける「会社の土台」を握る会社になる。

ただし、下振れも書いておく。即席アプリの重複や権限事故が増え、導入企業の保守費が削減額を超えれば、既存SaaSへ戻る。小さな会社はOS全体ではなく一業務・一接続から始め、30日で作業時間が20%以上減らないか、重大事故が1件でも出たら止める。それでも正本、接続、権限、監査の市場は残る。

結論。

Cloudflare OSが示したのは、SaaSが消える未来ではない。完成した画面の価値が下がり、正本、API、権限、監査を持つ会社が会社OSの部品として残る未来だ。これから一発当てたいなら、AIが会社で安全に働くための土台を握るしかない。

Summary

Cloudflare が公開したオープンソースの Cloudflare OS を「社内AI安全化ツール」ではなく「会社OSという新市場の号砲」と読む論考。社員がAIに頼めばその場で自分専用の業務アプリが生成される世界では、固定された管理画面や細かな便利機能を売るSaaSの価値が下がり、顧客台帳・決済・会計・契約・在庫といった「正しい記録」とそれを操作するAPI・認証・権限管理だけが部品として残る、という主張。そのうえで会社OS導入業・会社の文脈整備業・AIアプリ管理業の3つを新市場として提示している。

Key points

  • Cloudflare OS は PC 用 OS ではなく、社員がブラウザ上でAIに業務アプリや自動化を作らせるための「会社用の仕事場」
  • 社内では毎週数千人が使用、直近30日で4000以上のアプリ/ツールが生成されたとされる（公開版はまだ初期提供）
  • 消えやすいのは固定管理画面と便利機能、残るのは正本データ・API・認証・権限管理
  • 新市場①「会社OS導入業」: freee/kintone/SmartHR 等を安全にAIへ接続し権限設計する（日本ではJiteraが1,000超の外部アプリ接続を提供）
  • 新市場②「会社の文脈整備業」: 散在資料をAIが使える正本へ（Glean は100超のデータ源を権限保持のまま知識グラフ化）
  • 新市場③「AIアプリ管理業」: 社員が量産するAIアプリを台帳化・統制（SAP AI Agent Hub は150社で10万超を管理）
  • 課金モデルは「1人月額いくら」からAIの処理件数・データ参照・実行回数に応じた「エージェント従量課金」へ
  • 下振れシナリオも明示: 即席アプリの重複と権限事故で保守費が削減額を超えれば既存SaaSへ回帰。小さく1業務1接続から始め、30日で作業時間20%減らなければ止める

Takeaway

「AIが誰でも開発者にする」の次に来る問いは、作られたアプリをどう統制するか。安くなるのは画面・コード・知能で、希少になるのは正本データ・接続許可・操作権限・監査記録という整理は、自社でAI活用を進める側にとっても投資順序の指針になる。まず整えるべきは高性能なモデルではなく、AIに読ませてよい正本と、誰が何を実行できるかの権限設計。
