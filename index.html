The Curator — garbage collection - Inactivity check (not cron): 7 days since last run + 2+ hours idle → background fork - Phase 1 (deterministic): unused 30 days → stale, unused 90 days → archived - Phase 2 (LLM, up to 8 iterations): forked agent surveys skills, decides keep/patch/consolidate/archive - Never touches bundled or hub-installed skills (only agent-authored) - Never auto-deletes (only archives to ~/.hermes/skills/.archive/, recoverable) - tar.gz snapshot before every Curator pass — rollback in one command - hermes curator pin <skill> protects from archival/deletion (patches still allowed) GEPA (Genetic-Pareto Prompt Evolution) Companion repo: NousResearch/hermes-agent-self-evolution. ICLR 2026 Oral, MIT licensed. Reads execution traces (not asks "did you do well?") → understands failures → evolutionary search. Pipeline: 1. Read current skill from Hermes repo 2. Generate eval dataset (synthetic via Claude Opus, real from SQLite, hand-curated) 3. Run optimizer: traces → failure points → candidates 4. Evaluate with LLM-as-judge + rubrics 5. Constraint gates: 100% tests pass, <15KB skill size, caching compat, no semantic drift 6. Best variant → PR (never direct commit) $2-10/run. No GPU needed.
