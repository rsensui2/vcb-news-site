Claude Code はそのためにいくつかの仕掛けを持っているが、最近出荷したのが /goal だ。 Part 2 完了条件を設定すれば、Claude はそれが満たされるまで作業を続ける。 例: /goal all tests in test/auth pass and the lint step is clean（test/auth 下の全テストが通り、lint がクリーンになるまで） Part 3 /schedule は Claude を定期的に起動する。夜間のテスト実行、朝のトリアージ、週次のクリーンアップなどに。 Part 4 /loop は Claude を繰り返し走らせる。反復リファクタ、整理、バックログの消化に最適。 Part 5 これは Claude Code に組み込まれた「Ralph loop」だ。Claude が停止しようとするたび、トランスクリプトに対して条件をチェックする。 未達なら継続、達成なら「Goal achieved」サマリーを返す。 Part 6 長時間ジョブが回るのは、Claude が人間を待たなくていい場合だけ。だから auto モードがある（CLI なら shift+tab、デスクトップならモードセレクタで有効化）。
Part 1 (親ポスト) How do you keep Claude working until the job is done? Claude Code helps with this in a few ways, including one we shipped recently: /goal. Part 2 Set a completion condition, and Claude keeps working until it's met: /goal all tests in test/auth pass and the lint step is clean Part 3 /schedule kicks off Claude on a cadence. Nightly test runs, morning triage, weekly cleanup. Part 4 There's also /loop to run Claude on repeat. Great for iterative refactors, cleanups, or burning down your backlog. Part 5 It's the Ralph loop, built into Claude Code. Every time Claude tries to stop, it checks your condition against the transcript. Not done? It keeps going. Done? You get a "Goal achieved" summary. Part 6 Long-running only works if Claude doesn't have to wait on you. That's why we have auto mode, which you can enable with shift + tab in CLI or by using the mode selector on desktop.
