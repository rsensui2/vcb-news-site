OpenAI — GPT-5.5 正式ローンチ、Codex は GPT-5.5 ベースに刷新

OpenAI が GPT-5.5 を正式ローンチし、サム・アルトマンの GPT-5.5 ローンチパーティ告知が 6,037 likes を獲得。Greg Brockman は『Codex for shipping fast / startup ideas / ergonomics』とユースケース連投で訴求し、Codex を GPT-5.5 ベースの開発エージェントとして再定義した。OpenAIDevs は /hatch で Codex pet を作る Twitter 企画で ChatGPT Pro 30 日プレゼントを実施。

キーポイント

  • GPT-5.5 ローンチパーティを SF で開催し応募超過、サム本人が応募者全員にギフトを予告
  • 内部コードネームは spud、Gemini の対抗ステルスは kartoffeln（ドイツ語の potatoes）と関連付けられる観測
  • Greg Brockman が Codex のユースケース連投: startup ideas / shipping fast / ergonomics
  • Codex pets キャンペーンで /hatch 企画、ChatGPT Pro 30 日プレゼント
  • 開発者の体感では『GPT-5.5/Codex が新しい開発環境になった』との声が増加
  • ChatGPT Images の利用が really taking off と Greg が報告
GPT-5.5 はモデル単体ではなく『Codex を基盤とした開発エージェント』として再定義され、Vibe Coder Bootcamp 受講生は Codex CLI / ChatGPT Codex を GPT-5.5 前提で使い直す必要がある。Codex pets のような遊び要素が公式から出ること自体、開発者向け AI がエンタメ寄りに裾野を広げるフェーズに入った象徴。

The Information — 開発者は Codex 派と Claude Code 派に二分、競争が本格化

The Information が『開発者コミュニティは OpenAI Codex と Anthropic Claude Code で二分された』と報じた。Codex（GPT-5.5、2026-02 リリース）は速度・低トークンコスト・ペアプロ体験で支持を集め、Claude Code は長文計画力・設計で根強い。開発者の生の声では『Claude Code は premium で smart だが leash が短い、Codex はもっと直接的で出荷向き』(@anomsiiwa) という比較が拡散している。

キーポイント

  • Codex の強み（報道）: 速度、低トークン使用量、ペアプロ的フロー
  • Claude Code の強み（報道）: 設計力、研究系・複雑タスク
  • @shmidtqq の Claude Code 愚痴投稿（『プランを忘れる』『400行の不要コード』）が共感拡散
  • AWS が Bedrock 経由で OpenAI モデル提供開始、エージェント基盤の競争が一段と複雑化
  • 両方を使い分ける開発者が主流派になりつつある
『どちらか1つに張る』時代は終わり、エージェント開発者は両方を使い分けるのが既定路線になりつつある。Bootcamp としては、Codex / Claude Code の強みと弱みを使い分けるカリキュラム（出荷フェーズは Codex、設計フェーズは Claude Code 等）にアップデートする必要がある。

Cursor — Composer 2 が SDK で 50% OFF（週末限定）

Cursor 公式が『Composer 2 が SDK で週末 50% OFF』と告知。Composer 2 は Cursor の独自エージェントモデルで、SDK 経由で外部アプリケーションに Cursor のコーディングエージェントを組み込めるレイヤー。週末限定の半額セールで自社製品に組み込んで試す絶好のタイミング。

キーポイント

  • 対象: Cursor Composer 2（独自エージェントモデル）
  • 形態: Cursor SDK 経由で 50% OFF
  • 期間: 2026-05-03 週末限定
  • 1,138 likes と高エンゲージメント
Cursor がエディタ単体から『組み込み可能な開発エージェント基盤』へ拡張する戦略を明示。Bootcamp 受講生は自分のプロダクトに Cursor の AI を組み込む実験のハードルが下がる。Codex / Claude Code とは別軸の SDK 提供型エージェント が価格競争に入った。

Google Gemini — ステルス新モデル Spark Robin と Omni、I/O 前の地ならし

LM Arena に Google の新ステルスモデル Spark Robin が登場し、説明欄に『Rich Visual Response』と書かれている。画像/図解付き回答を返すマルチモーダル出力モデルと推定される。同時に Gemini アプリの動画タブで『Powered by Omni』の記述が漏出、Veo 3.1 の次世代（ネイティブ動画出力）の可能性が指摘されている。別ステルス kartoffeln（独語: じゃがいも複数形）も arena で目撃され、OpenAI の spud（GPT-5.5 内部名）への対抗ネーミングと噂される。

キーポイント

  • Spark Robin: arena 上のステルス、Rich Visual Response（図解付き回答）
  • Omni: Gemini 動画タブの裏側エンジン、ネイティブ動画出力候補
  • kartoffeln: arena 上で webdev に強いとの観察
  • Google I/O が近いタイミングでリーク連鎖
  • OpenAI の spud（じゃがいも）への対抗ネーミングという憶測
Google の次世代 Gemini は『テキストではなく図解・動画で答える』マルチモーダル出力を狙っている可能性が高く、ChatGPT/Claude が苦手な領域での差別化を狙う。テキスト回答 → 図解付き回答の UX 転換は、Bootcamp 受講生のプレゼン・教材作成ワークフローを根底から変える可能性がある。

AWS Bedrock に OpenAI モデルが乗った — エージェント市場の再編

AWS が OpenAI モデルを Amazon Bedrock 経由で提供する取引を発表。Bedrock の AI エージェント機能向け新オファリングとして組み込まれる。一方で既存顧客の中には『競合モデル（Claude / Llama 等）で十分』とする声もあり、OpenAI が AWS という流通チャネルを得たもののコモディティ化圧力にさらされる構図。

キーポイント

  • AWS Bedrock 上で OpenAI モデル提供開始（AI エージェント向けオファリング）
  • 一部顧客は『Claude や他社モデルで足りている』と表明
  • AWS / Anthropic / OpenAI のクラウド × モデル提携網が一段と複雑化
  • Anthropic の AWS Bedrock 寡占状態に楔
  • エージェント基盤・ツール生態系の戦争が本番フェーズへ
『特定のクラウド = 特定のモデル』の時代は完全に終わり、AWS 上でも OpenAI / Anthropic / Meta が並列提供される世界に。Bootcamp 受講生はクラウド選定とモデル選定を独立した意思決定として扱うべき。モデルプロバイダ側は『クラウドに乗っただけでは差別化にならない』フェーズに入り、エージェント基盤・ツール生態系の戦いが本番。
