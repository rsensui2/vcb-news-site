Anthropic × xAI/SpaceX Compute 提携 — Claude Code 5h レート上限が即日 2 倍化

Anthropic が xAI / SpaceX との大規模コンピュート提携を発表。xAI 側は Colossus 1（世界最大級の AI スパコン）の容量を Claude 提供向けに開放。Anthropic はこの追加 capacity を使い、本日付で Pro / Max / Team プランの Claude Code 5h レート上限を倍増、ピーク時間帯の削減撤廃、Opus 系 API レートの大幅引き上げを即日適用した。

キーポイント

  • Anthropic ↔ xAI/SpaceX 提携で Claude API + Claude Code 双方の usage limit を引き上げ
  • Claude Code 5h limit: Pro / Max / Team / 一部 Enterprise で 2 倍化
  • ピーク時間帯のスロットル削減を撤廃（Pro / Max）
  • Opus 系 API レート上限も大幅増
  • xAI: Colossus 1 を Claude のために開放（one of the world's largest）
  • @btibor91 は『weekly レート上限は据え置き』と冷静に指摘
Bootcamp 受講生で Claude Code を毎日叩いている層に直接効く。今日から Pro でも 5h 内のレート切れに当たりにくくなり、教材の前提が更新される。Anthropic のコンピュート調達が AWS Trainium と xAI Colossus にマルチソース化、ハイパースケーラー1社依存からの分散が業界標準化しつつある。weekly cap は据え置きなのでヘビーユーザーには未だ効かない点に注意。

OpenAI — GPT-5.5 Instant が ChatGPT のデフォルトモデルにロールアウト

GPT-5.5 Instant が ChatGPT のデフォルトとしてロールアウト開始。OpenAI 公式は smarter / clearer / more personalized / warmer / more concise と特徴を列挙し、Greg Brockman も Major ChatGPT upgrade と追認。同日に Excel / Google Sheets 向け ChatGPT アドインも GPT-5.5 ベースで公開された。

キーポイント

  • 既定モデルが GPT-5.3 Instant → GPT-5.5 Instant に置換
  • 公式アップグレード文言: smarter / clearer / more personalized / warmer / more concise
  • 全有料・無料層に段階展開
  • Excel / Google Sheets 向け ChatGPT アドインを同日公開（GPT-5.5 が裏で稼働）
  • @gdb が Major ChatGPT upgrade と公式追認
『無料層 = 一番モデルが弱い ChatGPT』という前提が今日から崩れる。Bootcamp 受講生の友人・家族が触る ChatGPT も GPT-5.5 になり、ChatGPT に何を聞けるかのリテラシー底上げが必要。Excel / Sheets アドインは表データ処理を OpenAI が表計算レイヤごと取りに来た最初の本格な手で、SaaS のセル単位 AI 機能を一気に巻き取る可能性。

Google Chrome が Gemini Nano 4GB をユーザー無断 DL — プライバシー炎上

Google Chrome が Gemini Nano の 4GB モデルファイル（weights.bin）をユーザー同意なし・通知なし・ポップアップなしで端末ローカルに自動 DL していたという指摘が拡散。複数言語圏でバイラルしており、Google のオンデバイス AI 戦略のサイレント配布姿勢にプライバシー懸念が集中している。

キーポイント

  • 対象ファイル: weights.bin (Gemini Nano のモデルウェイト)、サイズ ~4GB
  • DL タイミングはユーザー操作と無関係（バックグラウンド）
  • 同意ダイアログ・告知・ポップアップ・オプトアウトの導線なし
  • ポルトガル語圏 (@namcios) でも独立に拡散 → 単一インフルエンサー発ではない広域な話題
  • @k1rallik 投稿は 47,098 likes、@namcios 版は 16,150 likes
オンデバイス AI = ローカルだから安全という言説の弱点を一気に可視化。配布チャネル（ブラウザ自動更新）を握るプレイヤーが容量・更新タイミングを完全に握る構図は、エンタープライズ IT・教育機関・BYOD 環境で大きな policy 議論を呼ぶ。Bootcamp 受講生の自社 AI 導入相談で、Chrome 経由でモデルが既に入っている可能性を前提にした説明が必要になる。

OpenAI Agents SDK (TypeScript) — sandbox agents と OSS harness 同梱でアップデート

OpenAI Agents SDK の TypeScript 版が更新リリース。sandbox agents（隔離環境で動く agent 実行）対応と、OSS の harness（agent 動作枠組み）を同梱。Codex の npm 週次 DL 急増（5.7M → 163M）と同時期で、Codex のクライアント側エコシステムが TS 開発者向けに前進した形。

キーポイント

  • Agents SDK TypeScript 版が新リリース
  • sandbox agents をサポート（独立実行環境で安全に動かせる）
  • OSS harness 同梱 → 自前カスタマイズ前提のテンプレ提供
  • Codex npm 週次 DL 急増（5.7M → 163M）と同時期、TS 開発者の流入を取り込む布石
  • LangChain / LlamaIndex のレイヤを部分的に押しのける動き
TS / Node エコシステムにおける Agent 実装の公式リファレンスが OpenAI から提供された。Bootcamp の受講生に Codex CLI 単体使いから Agents SDK で自社サービス組み込みへの次ステップを提示できる。OSS harness 同梱で来期 1Q 内にフレームワーク選定の議論が整理される可能性。
