Claude for Microsoft 365 が GA — Excel / PowerPoint / Word + Outlook public beta

Anthropic が Claude for Excel / PowerPoint / Word を一般提供（GA）開始、Claude for Outlook は public beta となった。Microsoft 365 アプリ間を移動しても会話のコンテキストを引き継ぐ統合体験を打ち出し、Microsoft Copilot のお膝元で Claude が中で動く AI として正式に並ぶ形になった。

キーポイント

  • 対象: Excel / PowerPoint / Word — General Availability
  • Outlook は public beta（誰でも参加可）
  • アプリ横断で会話コンテキストを保持（Claude moves between your Microsoft apps）
  • @DudeWhoInvests のミーム投稿（Microsoft 開発者が Claude のほうが Copilot より統合うまく行ってると眺めてる）が 2,441 likes
  • 同日 Code with Claude カンファでも Microsoft Build 連携が発信
「Microsoft 365 = Copilot 一択」だった世界が崩れ、エンタープライズ IT 部門の AI 選定が「Copilot か Claude か」「両方入れるか」の議論に切り替わる。Bootcamp 受講生・経営層に Excel に Claude を入れる手順を見せれば即時に導入相談に化けるレベルの即効性。

Claude Mythos Preview が Firefox セキュリティ修正を激加速 — 4月単月で過去15か月の合計超え

Anthropic の Alex Albert が、新モデル Claude Mythos Preview の支援によって Firefox チームの 2026年4月単月のセキュリティバグ修正数が直前 15か月の合計を上回ったと公表。AI が実プロダクトの大規模脆弱性修正を定量的に底上げした初の説得力ある事例になっている。

キーポイント

  • 新モデル名: Claude Mythos Preview（次世代 Claude のプレビュー、価格・正式版日付は未公開）
  • 適用対象: Mozilla Firefox のセキュリティ修正フロー
  • 数字: 2026-04 単月の修正件数 > 直前 15 か月の合計
  • 情報源は Anthropic デベロッパー・リレーションズの Alex Albert（公式に近い）
「AI でコードレビューが速くなる」を超えて、AI でメジャー OSS のセキュリティ姿勢が定量的に変わるフェーズに入った。受講生・経営者に対し自社の脆弱性対応を AI に回す議論を始めるための数字として強い。Mythos という新コードネーム自体も、Anthropic が Opus / Sonnet ラインの上に別系統モデルを温めている兆候として注目に値する。

OpenAI Codex が Chrome 拡張として正式投入 — タブ並列バックグラウンド実行

OpenAI が Codex を Chrome 拡張として macOS / Windows に正式リリース。ブラウザを乗っ取らずに複数タブで並列にバックグラウンド実行できる仕様で、Codex アプリから Chrome plugin をインストールするだけで利用開始できる。アプリ・サイトとのインタラクション能力も強化された。

キーポイント

  • 対応 OS: macOS / Windows（Linux は未明示）
  • 動作: ブラウザを操作せず、バックグラウンドで複数タブを並列処理
  • インストール導線: Codex アプリ内から Chrome plugin
  • アプリ・サイトとのインタラクション能力が強化
Anthropic が Mac アプリ / VS Code 拡張で攻めるのに対し、OpenAI はブラウザを抑えに来た。Web アプリ / SaaS の操作は依然 Chrome が圧倒的シェアなので、業務オペを丸投げできる AI の戦場がブラウザに移る。Bootcamp 受講生にとっては Codex Chrome 拡張で SaaS 業務を自動化するが新たな実用テーマになる。

Cursor — /orchestrate スキルで再帰的エージェント生成、SDK 内蔵

Cursor が Cursor SDK 上で動作する新スキル /orchestrate を発表。再帰的にサブエージェントをスポーンして大規模タスクを分解実行する仕組みで、Cursor 自身も社内の skill 自動リサーチに使い、トークン消費 20% 削減 + eval スコア改善、内部バックエンドのコールドスタート 80% 削減を実現したと自社事例を公開した。

キーポイント

  • スキル名: /orchestrate（Cursor SDK 経由で配布）
  • 仕組み: ルートエージェントが要件を分解、サブエージェントを再帰的に生成・統括
  • 自社事例 1: 内部 skills の autoresearch でトークン消費 -20%、eval 改善
  • 自社事例 2: 内部バックエンドのコールドスタート時間 -80%
  • 同時期に Cursor 3.3 で context usage 内訳の可視化も提供
Cursor が 1ファイル編集ツールからエージェント編成プラットフォームに正式移行した日。Claude Code の Task や Codex の sandbox agents と同じ土俵に乗ってきた。reportsTo / provides でエージェント階層を組む Ryoko / Bootcamp 受講生プロジェクトとコンセプトが完全に一致する。

Anthropic — 金融サービス向け Claude Agent Templates 公開（ピッチ作成・バリュエーション・月次決算）

Anthropic が金融サービス向けに即実行可能な Claude Agent Templates を公開。ピッチ作成 / バリュエーションレビュー / 月次決算クロージング等の金融業務の典型タスクをカバーしたテンプレート群が、Cowork や Claude Code の plugin として導入でき、本番運用は cookbooks 経由の Managed Agents に載せ替えるパスが用意されている。

キーポイント

  • 対象業務: ピッチ資料作成・バリュエーションレビュー・月次クロージング 他

  • 本番運用: cookbooks 経由で Managed Agents としてホスト
  • 各 agent に必要な connectors / skills / subagents が同梱
  • 各社基準に合わせ as-is でもカスタムでも動く
