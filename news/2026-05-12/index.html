OpenAI、PE 連合と「Deployment Company (DeployCo)」を $14B 評価で設立 — Tomoro 買収で FDE 150 名も即調達

OpenAI が OpenAI Deployment Company (DeployCo / ODC) の設立を公式発表。OpenAI が過半数を保有・支配する子会社として、TPG・Advent・Bain Capital・Brookfield 主導の 19 社から $4B 以上を調達（評価額 $14B、投資家には最低 17.5% の利回りを確約）。同時に Tomoro 買収に合意し、Forward Deployed Engineer / Deployment Specialist 150 名を初日から確保する。

キーポイント

  • OpenAI が過半数を保有・支配する子会社、JV 形態
  • TPG / Advent / Bain Capital / Brookfield / SoftBank / Goldman Sachs / Warburg Pincus / Capgemini / Bain & Company / BBVA / B Capital 等 19 社が出資
  • 調達総額 $4B 超、評価額 $14B、最低利回り 17.5% を投資家に確約 (FT 報道)
  • Tomoro 買収で Forward Deployed Engineer 150 名を初日から保有
  • Goldman Sachs は OpenAI DeployCo と Anthropic 側ライバル取り組みの両陣営に出資
  • ミッション: PE 投資先企業に ChatGPT / GPT-5.5 / Codex / Image2 などフロンティア AI を本番展開
AI ベンダーが SI/コンサルレイヤを内製化する最初の本格的な動き。Accenture / Deloitte / BCG など既存 SI のポジションを上から圧迫する構造で、Anthropic 側もウォール街連合と同様の動きを進めており、「AI ロールアウト・インフラ」が新たな戦場になりつつある。

Karpathy 流 CLAUDE.md 4 ルールを 30 コードベースで実証 → 12 ルール拡張版でミス率 41% → 3% に

2026-01 に Karpathy が Claude のコード生成の 3 失敗パターン (silent wrong assumptions / over-complication / orthogonal damage) を指摘したスレッドを起点に、Forrest Chang が 4 ルール CLAUDE.md を作成し GitHub で 120,000 stars。著者 Mnimiy は 30 コードベース × 6 週間でこれを実測し、ミス率 41% → 11% を確認。エージェント時代の問題に対応する 8 ルールを追加し、12 ルール構成でミス率 3% を達成した。

キーポイント

  • オリジナル 4 ルール: Think Before Coding / Simplicity First / Surgical Changes / Goal-Driven Execution
  • 追加 8 ルール: 非言語タスクをさせない / トークン予算 / 衝突可視化 / 書く前に読む / テストはゴールではない / チェックポイント / コンベンション優先 / 可視に失敗する
  • ミス率: なし 41% → 4 ルール 11% → 12 ルール 3% (30 codebase × 50 tasks × 6 weeks)
  • コンプライアンス率はほぼ落ちない (78% → 76%) — 新ルールが旧 4 ルールと注意リソースを奪い合っていない
  • CLAUDE.md は 200 行を超えるとコンプライアンスが急落する性質あり
Vibe Coder Bootcamp / TEKION / Ryoko 配下の CLAUDE.md 整備に直接転用できる実証データ。「ルール追加で compliance が線形に落ちる」直感を打ち破る測定結果。Rule 10「checkpoints」と Rule 12「fail visibly」は daily-news-pipeline のような長尺パイプラインに即適用したい。

AI ロールアウト・インフラ戦線が同時開戦 — Anthropic + ウォール街も企業 AI サービス会社、Goldman は両陣営に出資

OpenAI の DeployCo 設立と同時期に、Anthropic もウォール街連合と組んで企業向け AI サービス会社を立ち上げたことが報じられた。Goldman Sachs は OpenAI DeployCo と Anthropic 側ライバル取り組みの両陣営に出資している唯一の投資家として両陣営をヘッジしている。

キーポイント

  • OpenAI DeployCo: 19 社、$4B+、$14B 評価、Tomoro 買収で FDE 150 名
  • Anthropic 側: ウォール街連合と企業 AI サービス会社（金額・名称詳細続報待ち）
  • Goldman Sachs は両陣営に出資、ヘッジ姿勢
  • 両陣営とも PE 投資先 / 大企業の AI 本番導入支援をターゲット
  • 既存 SI (Accenture / Deloitte / BCG) にとっては上流からの圧迫
2026 年は「AI ベンダー × PE × SI / コンサル」の三者連合が新しい流通チャネルとして成立する年になる。AI ベンダー自身が PE のポートフォリオ企業全体に一括導入をかける形態が現実化する。TEKION / Vibe Coder Bootcamp 視点では独立系現場実装支援の差別化が今後 6〜12 ヶ月の論点。
