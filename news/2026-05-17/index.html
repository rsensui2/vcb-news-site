Hermes Agent マスタークラス — Nous Research OSS、GitHub 90k stars、三層メモリ + 自己進化 + GEPA

/goal 完全ガイド — Anthropic / OpenAI / Hermes 横断で Ralph loop が標準化

`/goal` スラッシュコマンドの完全ガイド。Anthropic、OpenAI、その他主要 AI ベンダーが同時期に `/goal` を投入したのは偶然ではなく、Ralph loop ベースの自走エージェント設計が業界標準として確立しつつあることを示す。

キーポイント

  • 構文: `/goal [do the work] until [measurable end state] without [constraints that must hold]`
  • 例: `/goal fix every failing test until npm test exits 0 without modifying any file outside the /auth directory.`
  • Codex / Claude Code / Hermes Agent 全てで動作
  • ループ判定は小型モデルが行うため安価
  • 同時に 1 個まで、`/plan` とペアで使うのが定番、`/pause` / `/goal clear` で制御
  • Codex desktop / CLI、Claude Code CLI 全対応
VBC 受講生に Ralph loop を教えるための実用ガイドが揃った。サブスク中立、即明日から実践可能。

育てる Claude Code から勝手に育つ Claude Code へ — リポジトリ汚染への新陳代謝 4 本柱

Claude Code を半年使い込んだ全員が直面する「リポジトリ汚染・処理速度低下」問題への処方箋。'育てる' から '勝手に育つ' への転換、4 本柱: 摂取 / 代謝 / 排泄 / そもそも汚れにくい体質。

キーポイント

  • ① 摂取: X 投稿 URL を渡すと自動で要約・分類・スキル追記候補・新スキル草案を作る取込パイプライン
  • ② 代謝 (Gotcha): 各スキル末尾に「過去にハマったケース」セクション、1 回フィードバックで永久に賢くなる
  • ② 代謝 (Dreams): 横断パターンを週次抽出して `context/dreams.md` に蓄積
  • ③ 排泄: 月 1 で Claude Code に 3 つの問い (未使用スキル / 古い context / 遅延原因)
  • ④ 体質: SSoT (Single Source of Truth) + フロー (work/) とストック (context/) の物理分離
  • 法人向け Claude Code 研修サービスも同時リリース
Vibe Coder Bootcamp 受講者層に直接刺さる運用設計論。Gotcha は新人教育の暗黙知形式化としても応用可。
