米政府がClaude Fable 5 / Mythos 5の「非米国籍アクセス停止」を指示 → 実質全停止、AIモデルが戦略インフラ化

アメリカ政府がAnthropicに対し、Claude Fable 5とMythos 5への「アメリカ人以外（外国籍）のアクセス停止」を指示した。ET 17:21に受領した指令は『米国内外を問わず、Anthropic社員を含む米国籍以外の人物に両モデルへアクセスさせるな』というもの。外国籍ユーザーだけを技術的に選別停止するのは困難なため、結果的に全ユーザーへの両モデル提供停止に至り、現在は全員が利用不可になっている。

キーポイント

  • 発端は米政府からの直接指令（ET 6/13 17:21 に Anthropic が受領）
  • 「外国籍のみ停止」が技術的に困難なため、副作用として実質全ユーザー停止に
  • 一次情報は Anthropic 公式告知（anthropic.com/news/fable-mythos-access）、ぬこぬこ氏が AI Safety 文脈で人力整理
  • フロンティアモデルが先端ハードウェア同様の輸出管理・安全保障の対象になった初の具体例
  • 「怒りの矛先は Anthropic ではなく米政府」と状況の正確な理解を促す論調
フロンティアモデルが地政学・規制の対象となり、アクセスが突然絶たれるリスクが現実化した。AIを業務基盤に組み込む企業にとって、単一モデル依存の地政学リスクとフォールバック経路の必要性を突きつける事件。

Satya Nadella「エコシステムなきフロンティアは安定しない」— AI時代の企業は human capital と token capital を築け

Microsoft CEO Satya Nadella が、AI駆動経済における「企業の未来」を論じた長文エッセイを公開した。全企業が human capital（人の知識・判断・関係・独創性・パターン認識）と token capital（自社が構築・所有するAIケイパビリティ）の両方を築く必要があると主張。鍵は最良モデル選びではなく、モデルの上に両資本が複利で積み上がる「学習ループ（hill climbing machine）を自社所有すること」=これが企業の新しいIPになる、と説く。

キーポイント

  • human capital は token capital が育っても価値が下がらず、むしろ高まる（人間の主体性が token capital 成長の原動力）
  • 構成要素はプライベート evals（外部ベンチでなく自社成果で測る）、プライベート RL 環境、クエリ可能なナレッジベース
  • ジェネラリストモデルを差し替えても「社内ベテラン」の専門性を失わない状態が、来たる時代の支配権・主権のテスト
  • 「フロンティアモデル単体でなくフロンティアエコシステムを築け。価値が少数モデルに集中すれば政治経済が許容しない」
  • グローバル化の産業空洞化を引き合いに、価値が広く流れる設計の必要性を警鐘
「どのモデルを使うか」より「自社の学習ループをどう所有・内製するか」が経営の問いになる、という大局観。AI時代の組織設計を考える経営層・VBC受講者に有益な戦略フレーム。

Garry Tan の Claude Code セットアップ「gstack」が OSS 公開 — 23ツールを役割別エージェントに整理

Y Combinator を率いる Garry Tan が、自身が60日で本番サービス3本・機能40以上を出荷した Claude Code のセットアップ「gstack」を OSS 公開した。23個の opinionated な Claude Code ツールを、CEO・デザイナー・エンジニアリングマネージャ・リリースマネージャ・ドキュメントエンジニア・QA といった『役割』に整理したもので、設定一式が GitHub でそのまま流用可能になっている。

キーポイント

  • gstack = 23 のツールを役割（CEO / Designer / Eng Manager / Release Manager / Doc Engineer / QA）にマッピング
  • Garry Tan は YC 運営と並行し60日で本番3サービス・40+機能を出荷（ピーク日は3.7万行規模のコード生成との投稿も）
  • 設定一式が GitHub で公開され、自分の Claude Code にそのまま流用できる
  • 「1人＋AIで組織のように動く」具体的テンプレートとして拡散
役割ごとにツールを束ねる発想は、Claude Code を『個人の作業補助』から『擬似チーム運用』へ引き上げる実践テンプレート。Ryoko の org システム（employee 役割分担）とも思想が重なり、VBC受講者がすぐ取り入れられる。

Google が Gemini CLI を廃止し Antigravity CLI へ統合 — 開発者ツールの集約フェーズへ

Google の公式アカウント @geminicli が、Gemini CLI ユーザーを Antigravity CLI へ移行させると発表した。「取り組みを統一する（unifying our efforts）」として独立した Gemini CLI を畳み、AI開発環境 Antigravity 配下の CLI に集約する方向を示した。既存ユーザーには Antigravity（継続利用には Gemini Enterprise / AI Ultra）への案内が出ている。

キーポイント

  • Gemini CLI は Antigravity CLI へ統合・移行（公式アナウンス）
  • Google の AI 開発者ツールを Antigravity ブランドへ一本化する動き
  • 既存ユーザーからは「潮時か」「Enterprise を案内された」と移行コストへの戸惑いの声
  • 4-6月に launch した Antigravity（IDE/開発環境）への集約フェーズ
大手が乱立した CLI / 開発ツールを単一ブランドへ集約し始めた象徴例。Anthropic（Claude Code）・OpenAI（Codex）・Google（Antigravity）の三極が各々エコシステムを固めるフェーズで、VBC受講者はツール統廃合を前提に移行設計を考える必要がある。
