npm v12 が install スクリプトをデフォルト無効化 — サプライチェーン攻防が前進

GitHub が npm v12 で preinstall/install/postinstall などのライフサイクルスクリプトをデフォルトで実行しない破壊的変更を予告した。これは近年のワーム型サプライチェーン攻撃（Shai-Hulud 系・Miasma）が利用していた『依存を入れた瞬間にコードが走る』第一の侵入面を無効化するもの。同時期に、乗っ取られた開発者アカウント経由で npm・PyPI・GitHub Actions・AI コーディングエージェントの設定までを標的にする攻撃ツールキットが OSS 公開されたとの報告もあり、防御と攻撃が同時に高度化している。

キーポイント

  • npm v12 はインストール時のライフサイクルスクリプトを既定で実行しなくなる（破壊的変更）
  • Shai-Hulud / Miasma などワームが利用した最大の自動コード実行面を封鎖する防御策
  • 自前パッケージが postinstall に依存している場合は本番反映前に挙動確認が必要
  • 一方で npm・PyPI・GitHub Actions・AI エージェント設定まで狙う攻撃ツールキットの OSS 公開も報告され、AI 開発環境自体が標的化
  • 一次情報は github.blog の changelog（2026-06-09）
VBC 受講者は npm install を多用する。デフォルト無効化は安全性の前進だが、ビルド自動化や一部パッケージが壊れる可能性があるため、自分のプロジェクトが postinstall に依存していないか今のうちに点検する価値がある。AI エージェント設定が標的化され始めた点も CLAUDE.md や MCP 設定の扱いに直結する。

Transformer 共著者 Noam Shazeer が Google を離れ OpenAI へ移籍

Transformer 論文『Attention Is All You Need』の共著者で、Character.AI を創業し、その後 Google に戻って Gemini 開発を率いていた Noam Shazeer が、Google を離れ OpenAI に参画すると本人が発表した。『難しい決断だった』『Google のチームと築いたものを誇りに思う』と述べつつの移籍で、Views 760 万・Likes 1.4 万の大反響となった。

キーポイント

  • Noam Shazeer は現代 LLM の基盤である Transformer の主要発明者の一人
  • 2024 年に Character.AI から Google へ復帰し、Gemini 開発の中核を担っていた
  • 今回 Google を離れ OpenAI へ移籍することを本人ポストで表明
  • Google ↔ OpenAI 間のトップ研究者の流動が改めて鮮明に
フロンティアモデル競争が『モデル性能』だけでなく『キーパーソンの獲得』の局面に入ったことを示す象徴的な移籍。受講者が日々使う Gemini / GPT 系の今後の開発方針・速度に影響しうる。

Claude が編集できる OSS 動画エディタ「Palmier」が登場

Claude が直接編集できる AI ネイティブな動画エディタ『Palmier』がローンチされた。タイムライン上で AI が編集・素材整理・フッテージ生成を行い、Mac ネイティブかつオープンソースで Premiere 級の編集体験を無料で提供する。画像・動画・音楽の主要生成モデル（nb pro, gpt image, krea 2, recraft v4.1, seedance 2.0, kling v3, 11labs ほか）をタイムラインに統合している。

キーポイント

  • 自前の Anthropic API キー、または MCP 経由で Claude を接続して編集アシスタント化できる
  • メディア横断のセマンティック検索と文字起こしはオンデバイスで無料
  • オープンソース化により Premiere 級エディタが無料、プランは有料（ローンチ時半額）
  • 画像/動画/音楽の主要生成モデルをタイムライン内に統合
LLM エージェント（Claude）を動画編集という非コード領域のワークフローに組み込む具体例。MCP / API キー連携で『自分の Claude を専門ツールの操作役にする』設計は VBC のエージェント活用の好例で、OSS かつオンデバイス処理のためコスト・プライバシー面でも検証しやすい。

複数のコーディングエージェントを1セッションで束ねる「Omnigent」

『これからのコーディングは1体のエージェントではなく AI チーム』という主張のもと、Claude Code・Codex・Cursor・Pi などの異なるコーディングエージェントと自前エージェントを、1つのライブセッション内でチームとして同時に走らせられるツール『Omnigent』が紹介された。ベンダーをまたいで各エージェントの強みを混在運用する発想のオーケストレーション層。

キーポイント

  • 単一のライブセッションで Claude Code・Codex・Cursor・Pi＋独自エージェントを並走
  • ベンダー横断でエージェントを『チーム』として扱うオーケストレーション層
  • 『1エージェント最強』ではなく『混成チーム』へという潮流の一例
VBC でも『どのエージェントを使うか』より『複数をどう束ねるか』が論点になりつつある。ベンダー横断のマルチエージェント運用を試したい層に新たな選択肢を提供する。
