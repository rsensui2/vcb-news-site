Anthropic、Alibaba「Qwen」による過去最大級の蒸留攻撃を上院に告発 — 2,880万件の不正やり取り、米議会は対中制裁修正案へ

Anthropic が、Alibaba の Qwen ラボに紐づくオペレーターが Claude に対し『過去最大級の敵対的蒸留攻撃』を行ったと、米上院銀行委員会宛ての6/10付書簡で告発した(Bloomberg が6/24に初報)。約25,000の不正アカウントと商用プロキシで地理制限を回避し、2026/4/22〜6/5の6週間で約2,880万件のやり取りを生成したとされる。狙われたのはエージェント推論・ソフトウェア工学・長期タスク遂行という Claude の最も商業価値の高い能力だった。

キーポイント

  • 規模: 約25,000の不正アカウント・商用プロキシ経由で6週間に約2,880万件。中国エンティティを排除する地理制限を回避
  • 蒸留(distillation)とは: フロンティアモデルに大量クエリを投げ応答を収集し、安価な競合モデルの学習に使う手法。R&Dコストを払わず能力を再パッケージする行為
  • 議会の反応: Hagerty・Andy Kim 両議員が、不正に米AI出力へアクセスした中国企業を制裁・ブラックリスト化する修正案を必須の国防法案へ。下院でも超党派の関連法案
  • 法的シフト: 利用規約(ToS)違反の枠を超え、貿易法・制裁による対処へ。公開APIにクエリを流す行為への刑事枠組み化には懸念の声も
  • 前史: 2026/2 には DeepSeek・Moonshot・MiniMax の3ラボで計1,600万件超。4月の OSTP Kratsios メモの警告後に起きた『警告無視』案件
  • ⚠️ Alibaba はコメント拒否。Qwen が実際に Claude の能力で改善したか・IP侵害に当たるかは未確定
オープンウェイト competitor の『蒸留で安く追いついた説』に国家安全保障レベルで火がついた構図。モデル調達側にとって、地政学リスクが API アクセスや輸出規制を通じて供給に跳ね返る最新事例で、Anthropic 自身も Fable/Mythos の輸出停止で政府と板挟みになっている。

Google から Anthropic への AI 頭脳流出が止まらない — Gemini の Adler・Pritzel が移籍、『6日間で4人』の連鎖

Google の Gemini に主要貢献してきた研究者 Jonas Adler と Alexander Pritzel が Anthropic へ移籍する見込みと Bloomberg が6/24に報じた。Adler は AI コーディング、Pritzel は事前学習(pretraining)が専門。Noam Shazeer(→OpenAI)、John Jumper(→Anthropic)に続き、直近6日間で Gemini から計4人(Anthropic へ3、OpenAI へ1)の上級研究者が抜ける連鎖の最新となる。

キーポイント

  • 専門: Adler のコーディング研究は Cursor/Codex/Claude Code との競争に直結。Pritzel はモデルが大規模データから学ぶ pretraining 初期段階を担当
  • John Jumper との縁: 2人ともノーベル賞の AlphaFold 研究で Jumper と協働。先に Anthropic へ移った Jumper(06-21既報)に合流する形
  • 6日で4人: Shazeer(→OpenAI)・Jumper(→Anthropic)・Adler・Pritzel(→Anthropic)。全員 Gemini 出身
  • 動機: 最大の引力は IPO 前のエクイティ。『Google は給与は出せても、上場前の $100B 級企業に入る upside は出せない』。一部は計算資源配分を巡る方針対立も背景
  • 構造傾向: SignalFire 2025 分析で『DeepMind エンジニアは逆方向の約11倍 Anthropic へ流れやすい』。提携相手の Google から積極的に吸い上げ
  • ⚠️ 両社・本人とも公式コメントなし(関係者情報ベース)
フロンティアラボは『最難問を解ける少数の人間』で回る。その中核を上場直前の2社に1週間で4人奪われる事実は、Gemini の競争力そのものより『次の研究者が残るか去るか』の判断材料として効く。AI 業界の重心が pre-IPO スタートアップへ傾く象徴。

Claude Code & Developer Platform、6月下旬の実務アップデート群 — /rewind・90秒コード実行の明示・web_search の response_inclusion・refusal は非課金に

Anthropic が Claude Code 本体と Developer Platform で品質・実務系のアップデートをまとめて投入した。Claude Code 側は /clear 前の会話を復元する /rewind や権限・MCP 周りの安定化、長時間セッションの CPU/メモリ削減。API 側は code execution の90秒上限をツール説明に明示し、web_search/web_fetch に応答制御を追加、refusal を非課金化するなど、エージェント運用の細部が改善された。

キーポイント

  • Claude Code: /clear 前の会話を復元できる /rewind、バックグラウンドエージェント停止の恒久化、スクロール位置固定、MCP レジリエンス・OAuth 改善、ストリーミング/長時間セッションの CPU・メモリ削減
  • /install-github-app: GitHub Actions ワークフロー設定が任意に(App だけ入れて workflow/secret 手順をスキップ可能)
  • code execution: code_execution_20260521 で『1セル90秒』の実行上限をツール説明に明示 → LLM が長時間セルの予算を立てやすく(beta ヘッダ不要)
  • web search/fetch: web_search_20260318 / web_fetch_20260318 で response_inclusion を追加。消費済み結果ブロックを API 応答から落とせる(文脈節約、beta ヘッダ不要)
  • 課金: stop_reason='refusal' で出力ゼロのリクエストは非課金に。advisor ツールは max_tokens でコール毎の出力上限を指定可能
  • Multiagent sessions / Outcomes が managed-agents-2026-04-01 ヘッダで public beta に
VBC 受講者が日々触る Claude Code / API の『地味だが効く』改善群。特に web_search の response_inclusion と90秒上限の明示は、長時間エージェントの文脈汚染・タイムアウト事故を直接減らす。refusal 非課金化はコスト面の地味な朗報。

Micron × Anthropic、AI インフラ供給で長期提携 — メモリ/ストレージ設計を『フロンティアモデルの要求』に直結、Series H にも出資

Micron と Anthropic が、AI インフラの供給で提携したと6/22に発表した。AI メモリアーキテクチャ・ストレージ設計・供給計画・Micron 社内での Claude 利用、さらに Anthropic の Series H への戦略的出資までを含む包括的な内容で、フロンティアモデルの要求をインフラの設計・大規模展開に直接結びつける狙いがある。

キーポイント

  • 範囲: AI メモリアーキテクチャ、ストレージ設計、供給(supply)計画の連携、Micron 社内での Claude 活用、Anthropic への戦略出資という多層パッケージ
  • 位置づけ: $965B 評価・$47B ARR 級で急拡大する Anthropic のサプライチェーン固め。学習・推論に必要な HBM/メモリ確保がフロンティア競争の制約条件に
  • 文脈: Jalapeño チップ(OpenAI×Broadcom, 06-26既報)・Cerebras×OpenAI(06-25既報)に続く『フロンティアラボ × 半導体/メモリ』垂直連携の流れ
  • ⚠️ 金額・出資比率など詳細は限定開示
モデルの賢さ競争の裏で進む『メモリ・コンピュート供給の囲い込み』。推論コストや供給安定性は API 価格・エージェント運用の経済性に直結し、調達側が見るべきインフラ前提が動いている。
