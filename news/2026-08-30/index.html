OpenAI、SpaceX傘下のCursorへのモデル提供を終了へ

OpenAIは、SpaceXによるCursor買収を受け、Cursorへのモデル提供契約を終了する方針を公表した。契約上の最大猶予を使い、提供停止日は2026年11月12日を提案している。

キーポイント

  • OpenAIとCursorの協業は約4年間続いていた
  • 契約の変更支配条項に基づき、提供を終了する
  • OpenAIが提案した提供停止日は2026年11月12日
  • 今後登場するOpenAIモデルもCursorへ提供しない方針
  • Cursorは8月14日にSpaceX傘下へ入ると発表していた
AI開発環境で使えるモデルは、性能だけでなく企業間契約でも変わる。Cursorを標準化している組織は、特定モデルを前提にした手順を見直し、代替モデルでも品質を再現できる状態を作っておきたい。

Claude Code 2.1.248、制限モードとセッション間通信を追加

AnthropicはClaude Code 2.1.248を公開した。コマンド実行やWeb取得を外した`--restricted`モード、同一端末上のセッション間通信、エージェント単位のキャッシュ設定が加わり、長時間セッションの不具合も修正された。

キーポイント

  • `--restricted`はコマンド実行、コード実行、WebFetchを既定で外す
  • Bedrock、Vertex AI、Foundryでも同一端末のセッション間通信に対応した
  • エージェントごとに5分または1時間のキャッシュTTLを指定できる
  • OAuth更新時に起きていたプロンプトキャッシュミスを修正した
  • Remote Controlの権限表示と再接続を改善した
自律実行を強めるほど、権限を狭める入口とセッション間の連携が同時に必要になる。用途別のエージェントへ最小限の権限を与え、必要な連携だけを許す設計へ進めやすくなった。

Cloudflare Workers AI、GLM-5.3の提供を開始

Cloudflareは、Z.aiのエージェント型コーディングモデルGLM-5.3をWorkers AIで提供開始した。100万トークンを超えるコンテクスト、関数呼び出し、推論、構造化出力をCloudflareのAPIから利用できる。

キーポイント

  • モデルIDは`@cf/zai-org/glm-5.3`
  • コンテクスト長は1,048,576トークン
  • 入力は100万トークンあたり1.40ドル、キャッシュ入力は0.26ドル
  • 出力は100万トークンあたり4.40ドル
  • Workers PaidまたはAI Gatewayの前払いクレジットが必要
長時間コーディング向けモデルを、自前のGPUなしで試せる。Cloudflare WorkersやDurable Objectsを使うエージェントでは、実行基盤とモデル呼び出しを同じ運用面へ寄せられる。

〈知見〉成功ログを畳み、エージェントのトークン消費を減らす

テストが数千本ある開発では、処理を並列化しても成功ログが数千行出れば、エージェントへ返すコンテクストを圧迫する。成功時は要約だけを返し、失敗時だけ詳細を展開するラッパーなら、調査に必要な情報を保ちながらトークン消費を抑えられる。

キーポイント

  • 問題はテスト時間だけでなく、出力行数にもある
  • 成功時は件数と所要時間へ圧縮する
  • 失敗時は該当テストの詳細を残す
  • 元ログは別途保存し、再現に必要な情報を失わない
  • CIや監視、検索結果の出力設計にも応用できる
AI開発では、コードの最適化だけでなくツール出力の形もコストと精度に効く。正常系は短く、異常系は具体的に返す設計は、日常の自動化へすぐ取り入れられる。
