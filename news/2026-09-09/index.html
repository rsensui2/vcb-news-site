ChatGPT Images 2.5で部分編集をしやすく

OpenAIは9月8日、画像の一部だけを直す精度と、編集を繰り返した際の一貫性を改善したChatGPT Images 2.5を公開した。生成の待ち時間もImages 2.0比で最大50%短くしたと説明している。

キーポイント

  • 参照写真の被写体や、変更を指示していない部分を保ちやすくした。
  • Sketchで描いたラフを参照にでき、画像上のコメントでも修正箇所を伝えられる。
  • APIには速さを重視するFlareと、精密な制作向けのSunburstを追加した。
  • ChatGPT・ChatGPT Work・Codexの全プランへ順次展開。速度と品質はOpenAIの説明に基づく。
商品画像やチラシでは、元画像を残して一部分を直す仕事が多い。同じ素材で修正を重ね、残したい要素が維持されるかを試すと違いを確かめやすい。

Claude Code 2.1.265のプラグイン配布と再開処理

Claude Code 2.1.265は、複数のプラグインをまとめたフォルダを指定して読み込む機能を追加した。サブエージェントを再開した際に、同じ入力を再利用するプロンプトキャッシュが効かなくなる不具合も修正している。

キーポイント

  • --plugin-dir配下のプラグイン追加・削除を、実行中にも検知する。
  • 再開時にツール一覧やシステム指示が変わり、キャッシュを再利用できなくなる問題を修正。
  • ディスクに保存するツール結果に1GBの上限を設け、切り詰めた場合は会話内に表示。
  • Remote Controlで返答の最後より先に終了通知が出る不具合も修正した。
長い作業を再開して使う人に関わる更新だ。自作プラグインを配布する場合は、フォルダ構成と読み込み結果も合わせて確認したい。

03TOPIC 03 · OPENBMB / HUGGING

MiniCPM5-2Bを手元の端末で試す

OpenBMBがローカル実行向け言語モデルMiniCPM5-2Bの重みを公開した。総パラメータ数は約25億、文脈長は131,072トークンで、Apple Silicon向けMLX版やGGUF版も案内している。

キーポイント

  • 標準のLlamaForCausalLM構成を採用し、Apache-2.0で公開。
  • GGUF版はllama.cpp・Ollama・LM Studio、MLX版はApple Silicon向け。
  • ツール呼び出しを想定した手順と、vLLM・SGLangでの実行例を提供。
  • 掲載された性能比較は開発元の評価。日本語の業務精度や実機速度は個別の検証が必要。
小型モデルを自分の端末で試す候補が増えた。短い分類や情報抽出など用途を絞り、普段の入力で正答率と応答時間を測るところから始められる。

04TOPIC 04 · LANGCHAIN
コンテキスト設計 / LANGCHAIN / NEWS

Deep Agentsは担当に応じて会話を渡し分ける

LangChainはDeep Agentsで、サブエージェントへ親の会話を引き継ぐforkと、新しい文脈で始めるisolatedの使い分けを公開した。調査の経緯を引き継いで実装する担当と、独立して成果を点検する担当で、渡す情報を変えられる。

キーポイント

  • 既定のisolatedは、親が指定したタスクの説明から始める。
  • forkは親の会話履歴と状態を引き継ぎ、同じ資料の再読を減らせる。
  • 公式例は修正の実装にfork、独立レビューや単独の調査にisolatedを使う。
  • forkはプロンプトキャッシュの再利用を考慮した設計。ただし削減量は作業による。
実装を引き継ぐ人には経緯が役立ち、独立した点検では先入観が邪魔になることもある。AIへの仕事の分け方にも同じ観点を使える。

05TOPIC 05 · JAMES PHOENIX
エージェント設計の知見 / JAMES PHOENIX / NEWS

〈知見〉設計と実行でモデルを分ける

James Phoenixは、用途を絞ったAI処理について、高性能モデルで実行スクリプトを作り、日々の処理は低価格モデルに任せる設計を紹介している。入力の分解や振り分け、検証をコード側へ移し、モデルが答える範囲を小さくする考え方だ。

キーポイント

  • 対象は「一種類の文書・一つの問い・決まった出力形式」に絞れる仕事。
  • 実行例ではツールを持たせず、応答を1ターンに限定する。
  • 正解が分かる入力を50〜100件ほど幅広く試し、失敗の種類ごとにスクリプトを直す手順を提案。
  • 個人の設計知見であり、汎用エージェントで同じ効果が出るという実証ではない。
定型の抽出や分類を繰り返す仕事なら、まず正解付きの評価用データを用意したい。安いモデルへ替えた後も、品質を比較する基準が残る。

約90億の遺伝子変異予測をAlphaGenome Atlasで公開

Google DeepMindは9月8日、ヒトゲノムで起こり得る約90億の一塩基変異について、分子への影響を予測したAlphaGenome Atlasを公開した。事前計算した結果を、Web画面・API・Google AntigravityのSkillから参照できる。

キーポイント

  • 約1ペタバイトの予測データと、影響を順位付けするAVIスコアを提供。
  • 遺伝子の働きを調節する領域も含め、予測の根拠となる特徴を表示する。
  • 非商用の研究用途で利用可能。Atlasの商用提供はGoogle Cloudで近日予定。
  • 臨床用途での検証・承認は受けていない。予測結果は実験による確かめが必要。
大量の予測を事前に計算し、検索しやすいデータと操作手段を配る事例だ。研究者が個別の仮説を調べるまでの作業を減らす狙いがある。
