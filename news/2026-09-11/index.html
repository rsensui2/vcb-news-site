Claude Codeの料金表示と接続修正

Claude Code 2.1.268は、自社用の接続口で設定した料金をクライアントにも配り、/costと利用額の表示を揃える機能を追加した。一部の互換APIで毎ターンHTTP 400が発生する不具合や、WebFetchが終わらない問題も修正している。

キーポイント

  • gateway.yamlの料金設定をクライアントへ配布。
  • 2.1.265以降の互換API接続エラーを修正。
  • WebFetchの待機期限は既定300秒。設定で変更できる。
自前の接続先を使うチームに関わる更新だ。更新後は、普段の依頼が通るかと料金表示が合うかを同じ作業で確かめたい。

金融データを内蔵したChatGPT

OpenAIは9月10日、ChatGPT for Financial Servicesを発表した。GPT-6 Astraと金融データを組み合わせ、企業調査、財務モデル、顧客向け資料の作成を支援する。対象は利用条件を満たす金融機関。

キーポイント

  • Daloopa・PitchBook・LSEG News・Crunchbaseなどのデータを内蔵。
  • 数値の根拠となる表や文章を引用で確認できる。
  • 管理者がExcel・Word・PowerPointの社内テンプレートを配布。
業種に合うAIを考える際は、参照するデータと成果物の書式まで含めて設計する参考になる。既存のデータ契約との共有サインインは準備中で、すべて提供済みとは限らない。

社内データに質問して分析画面を作る

ChatGPT WorkのData agentは、許可された社内データに接続し、質問をもとに調査して共有可能なダッシュボードを作る。社内用語や指標の定義を参照し、接続アカウントの既存権限を引き継ぐ。

キーポイント

  • BigQuery・Snowflake・Databricksなどのデータに接続。
  • テーブル・行・列の閲覧制限をクエリにも適用。
  • Slackやメールへの共有、接続先での操作は承認した内容を実行。
先に売上や継続率の定義を揃えておくと、質問する人が変わっても分析を比べやすい。導入時は、見られるデータの範囲と指標の定義を一緒に点検したい。

GPT-Live-1で会話と推論を分担

OpenAIは9月10日、GPT-Live-1をAPIで公開した。相手の声を聞きながら話し、途中の割り込みにも対応する音声モデルで、深い推論やツール操作は別のモデルやエージェントへ任せられる。

キーポイント

  • 会話のトーンやペースを指示で調整。
  • 推論・操作の担当にはGPT-6 Astraや外部モデルを選べる。
  • 発話を中断しても裏側の作業は自動では取り消されない。
音声で注文や予約を受ける仕組みでは、会話の中断と処理の取消しを分けて設計する必要がある。話し方に加え、確認・権限・作業状態をアプリ側で管理する点が実装の要になる。

Codexの作業場所を分ける実験機能

Codex CLI 0.154.0は、別の作業用チェックアウトを作る実験的なworktree機能を追加した。Codexが作業を続けている間に、提案された選択肢や自由文で質問に答える機能も加わった。

キーポイント

  • --worktreeや/worktreeで作業用チェックアウトを作成・再開。
  • 進行中の質問へ入力中の原稿を失わずに回答。
  • GPT-6 Astraをモデル選択とAmazon Bedrockの一覧に追加。
  • 非推奨だったcodex mcp-serverの入口は削除。
同じリポジトリで別の変更を進めるとき、ファイルの混線を避ける選択肢になる。worktree機能は実験段階なので、既存作業を残せる小さな変更から試したい。

Claude Marketplaceの購入先が増加

Anthropicは9月9日、Claude MarketplaceにCursor、CrowdStrike、Factory、Gamma、Vercelを追加したと案内した。既存のAnthropic利用契約で約束した支出の一部を、対象のClaude搭載製品の購入に充てられる。

キーポイント

  • 既存のAnthropic利用コミットメントがある企業向け。
  • パートナー製品の請求はAnthropicが管理。
  • 振り向けられる金額や適用条件は担当窓口で確認。
個別に契約していた開発・資料作成ツールを調達する際の選択肢が増える。価格が下がるとは限らないため、既存契約と対象製品の条件を比較したい。

v0で認証やメールを接続

Vercelは9月9日、v0にResend、Amazon OpenSearch、MongoDB Atlas、Algolia、Clerkの接続機能を追加した。作りたいものを伝えるとチャットに接続カードを出し、接続後の設定も行う。

キーポイント

  • 接続先に必要な環境変数や設定を自動で用意。
  • 提供元が公開するagent skillsがあれば自動で読み込む。
  • ResendではReact Emailを使うメール機能も生成。
画面の試作から、ログインやメール送信を含むアプリへ進む手間を減らす更新だ。接続した後は、自分のアカウントで実際の操作が通るかまで確かめたい。

OpenClawの更新を事前に試す

OpenClaw 2026.9.3は、本番へ反映する前に隔離した状態で更新を試す仕組みを拡充した。複数の作業場所で同じSkill集合を使うSkill Workshopの管理も改善している。

キーポイント

  • コアとプラグインの変更を隔離環境で検証。
  • 温まったプロンプトキャッシュやworkerビルドを再利用。
  • Node 24系は24.16.0以上、26系は26.1.0以上が必要。
常駐エージェントを更新する人は、先にNodeの対応版を確認したい。Node 22・25などは対象外で、単に「24以上ならよい」とは判断できない。
