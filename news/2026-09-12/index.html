Copilotの操作権限を企業で統一

GitHub Copilot BusinessとEnterpriseの管理者が、エージェントの操作を禁止・人の承認が必要・確認なしで許可に分けて管理できるようになった。コマンド、ファイルの読み書き、接続先ドメインが対象になる。

キーポイント

  • 個人設定や自動承認で企業の制限を緩められない。
  • チームごとに異なるポリシーを設定できる。
  • Copilot app・CLI・Agent Hostを使うVS Codeで一般提供。
AIに任せられる範囲を、各自の判断だけに頼らず揃えられる。まず自社で使うクライアントが対象かを確かめ、承認が必要な操作を決めておきたい。

GitHub Copilotを共通の呼び出し口で使う

VercelのAI SDKに、GitHub Copilotを扱う公式アダプターが加わった。Claude CodeやCodexなどと同じHarnessAgentの仕組みで呼び出せるため、アプリ側のコードを保ちながらエージェントを切り替えられる。

キーポイント

  • 公式パッケージは@ai-sdk/harness-github-copilot。
  • HarnessAgentから他の対応エージェントと同じ形で利用。
  • 内部の接続にはAgent Client Protocolを使う。
  • Harnessパッケージは実験段階で、変更の可能性がある。
同じ依頼を複数のエージェントで試すアプリを作りやすくなる。呼び出し方が揃っても、利用条件や挙動まで同じになるわけではない。

Vercel Sandboxの保存容量が64 GBに

Vercel Sandboxの保存容量が32 GBから64 GBへ増えた。Vercelの管理イメージ、自作イメージ、旧runtime指定で作る環境も対象と案内している。

キーポイント

  • 保存容量は32 GBから64 GBへ倍増。
  • 大きなリポジトリや依存パッケージを置きやすくなる。
  • ビルド成果物や一時データを使う処理向け。
コードと成果物を同じ作業環境に置く際の余裕が増える。これはディスク容量の変更で、メモリやCPUが倍増するという意味ではない。

Vercel Connectの管理者を絞れる

Vercel Connectで、外部サービスへの接続設定を作成・管理できる人を制限できるようになった。ProとEnterpriseのチームが対象で、Ownerがチーム設定から制限を有効にする。

キーポイント

  • 有効化後はOwnerかConnector Manager権限が必要。
  • チームで管理する認証情報を使って外部サービスに接続。
  • 設定場所はTeam SettingsのConnector Permissions。
外部サービスとAIをつなぐ際、接続設定を変更できる担当者を明確にできる。接続を利用する操作の承認と、接続自体を管理する権限は分けて考えたい。

AnthropicがAI悪用の事例を公開

Anthropicは9月の脅威情報レポートで、2025年12月から2026年8月に検知・阻止したAI悪用の事例を公開した。サイバー攻撃、監視、詐欺など7分野を扱い、関係するアカウントへの対応と防御策の改善を説明している。

キーポイント

  • 対象は過去に検知・阻止した活動。
  • 7分野の目立つ事例を紹介し、一般的な発生率は示していない。
  • 攻撃の速さ・規模・深さにAIが与える影響を整理。
AIによる操作を導入するときは、実行記録と権限の管理も運用に含めたい。紹介された事例から、AI利用全体の危険度や特定モデルの優劣を直接推定できない。

vLLM MetalでMacのローカルAIを拡張

vLLM Metal 0.29.0が公開され、Apple SiliconのMacで扱えるモデルと検索用の埋め込みモデルが増えた。LFM2系などへの対応を広げ、公式のQwen3-Embeddingと多言語E5にも対応する。

キーポイント

  • Apple Silicon・macOS 15以降・arm64 Python 3.12が対象。
  • 公式Qwen3-Embeddingと多言語E5を利用可能。
  • 一部のハイブリッドモデルのキャッシュは実験段階。
Mac上で文章を検索用の数値に変換し、ローカルの文書検索を試す選択肢が増える。対応モデル、必要なメモリ、キャッシュの制約を確認してから使いたい。
