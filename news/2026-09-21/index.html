Claude Codeが共通の指示書AGENTS.mdに対応

Claude Code 2.1.277は、CLAUDE.mdがない場合に開発AIへの指示書AGENTS.mdを読み込むようになりました。設定画面で切り替えられますが、Bedrock・Vertex・Foundryなどのクラウド経由にはまだ対応していません。

キーポイント

  • CLAUDE.mdがない場合の代替として読む
  • /configのProject instructionsで変更
  • Bedrock・Vertex・Foundryは現時点で対象外
複数の開発AIで指示書を共有しやすくなります。既存のCLAUDE.mdが優先される点を確かめてから整理しましょう。

Claude Codeの自動判定費用を確認しやすく

Claude Code 2.1.278は、auto modeで操作の安全性を調べる処理を、対応環境ではサーバー側に任せる設定を既定にしました。サーバー側で行う判定には追加料金がかからず、従来の有料判定へ戻る場合は警告が出ます。

キーポイント

  • API・Enterpriseや対応クラウドが対象
  • /statusでAuto mode serverを確認
  • 判定が従来方式に戻ると課金が続く
自動実行の費用を調べる際、通常の推論と安全判定を分けて確認できます。サーバー側判定の対応状況は接続経路や地域によって異なります。

mcp-handlerがWebMCPに実験対応

mcp-handler 2.2.0が、ブラウザー内のAIへ操作機能を渡すWebMCPに実験対応しました。サーバーがセッションCookie認証に対応していれば、指定したツールをログイン中の利用者として呼び出せます。

キーポイント

  • 公開するツールを許可リストで指定
  • セッションCookie認証への対応が必要
  • 対応ブラウザーなどでスクリプトを追加
既存の検索や業務操作を、Web画面内のAIに渡す方法が増えます。実験段階のため、まず参照だけを行う機能で動作を確かめるのがよさそうです。

v0で社内の非公開部品を使える

v0が、Vercelの共有環境変数に登録した認証情報で非公開パッケージを取得できるようになりました。社内で共通の見た目や機能を持つ部品を、そのまま画面づくりに使えます。

キーポイント

  • npm用はNPM_TOKEN、独自の配布元はNPM_RC
  • 共有設定は開発用・確認用の環境に適用
  • 認証情報はモデルや作業用ファイルへ渡さない設計
試作の段階から社内のデザインや実装を使いやすくなります。既存部品を再利用できれば、本番向けに作り直す手間を減らせそうです。

GLM 5.3 FlashXをAI Gatewayから利用

Vercel AI GatewayがGLM 5.3 FlashXに対応しました。Vercelは毎秒約200トークンの出力速度を案内しており、コード生成やツールを繰り返し使う処理向けの選択肢になります。

キーポイント

  • モデル指定はzai/glm-5.3-flashx
  • 約200トークン毎秒は提供元の案内値
  • AI Gatewayで利用量と費用を確認できる
AIの返答待ちが長い処理で、速度と品質を比較する候補が増えます。案内された速度が手元の処理でも出るかは、実際の入力で確かめる必要があります。

Copilotレビューで残る指摘を追いやすく

GitHub Copilotのコードレビューが、未対応・前回から解決済み・再レビューで新たに見つかった指摘を分けて表示するようになりました。指摘には短いタイトルが付き、対応条件を満たす修正提案をまとめて採用する際のコミット文も生成します。

キーポイント

  • 未対応と解決済みを概要で見分ける
  • 再レビューで見つかった既存の問題も表示
  • 利用者が未解決のまま残すと返信した指摘を維持
修正と再レビューを重ねても、残った問題を見失いにくくなります。AIが解決済みとした項目も、テスト結果と合わせて確認しましょう。

npmに直接公開を許可しないトークン

npmに、パッケージを公開前の確認場所へ提出できる自動処理用の認証情報「stage-onlyトークン」が加わりました。このトークンでは直接公開できず、保守担当者が二要素認証を使って承認してから公開します。既存パッケージが対象で、導入するかどうかは選べます。

キーポイント

  • 自動処理はnpm stage publishで提出
  • 直接のnpm publishは拒否される
  • タグ変更や廃止指定の権限は残る
  • 既存トークンの公開権限は変わらない
自動化に任せる範囲と、人が公開を決める段階を分けられます。stage-onlyにも書き込み権限が残るため、読み取り専用とは区別して管理します。
