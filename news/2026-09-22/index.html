Grok 4.7をAI Gatewayで試せる

Vercel AI GatewayにGrok 4.7が加わり、9月27日まで利用料金が40%割引になります。一度に扱える文脈の長さは50万トークンで、推論の深さを4段階から選べます。

キーポイント

  • 割引は9月27日まで自動適用
  • モデルIDはspacexai/grok-4.7
  • 推論はlow・medium・high・xhighの4段階
比較するときは、同じ課題で精度・待ち時間・利用料金を記録すると選びやすくなります。

GitHub CopilotにもGrok 4.7

GitHub CopilotでGrok 4.7の段階的な提供が始まりました。VS CodeやCopilot CLIなどのモデル選択欄から利用でき、料金は提供元の定価に基づく従量制です。

キーポイント

  • 順次提供のため、まだ表示されない場合がある
  • 組織の管理者はモデルポリシーで利用を制御
Copilotでの料金と、Vercelの期間限定割引は別の条件です。普段使う接続先の料金を確認しましょう。

Vercelのビルド利用量を確認

Vercelでデプロイごとの請求対象時間とCPU分を確認できるようになりました。画面、CLI、REST APIから、各ビルドが利用量に占める分を調べられます。

キーポイント

  • 請求対象時間はビルドと後処理の合計を分単位で切り上げ
  • CPU分は請求対象時間にvCPU数を掛けて算出
  • CLIでの表示は59.23.1以降に対応
時間が短いビルドでも、CPU数が多ければ利用量は増えます。時間とCPU数を合わせて見るのがポイントです。

TeamsボットをVercelから接続

Vercel ConnectがMicrosoft Teamsに対応しました。アプリやエージェントがチャネルでの呼びかけやDMを受け取り、ボットとして返信できます。

キーポイント

  • テナント管理者とAzureサブスクリプションが初期設定に必要
  • EntraアプリとAzure Botの登録はVercelが担当
  • トークンは必要時に取得し、自動更新
Teamsを使う職場でも、チャットから呼べる業務アプリを作りやすくなります。導入時は管理者と接続先の環境を決めておきましょう。

GitHubの認証情報をCSVで棚卸し

GitHub Enterprise Cloudで、企業のGitHub環境にアクセスできる鍵やトークンの一覧をCSVに出せるようになりました。所有者や権限、利用日などを確認でき、トークンの値そのものは出力されません。

キーポイント

  • Enterprise所有者または専用権限を持つ利用者が対象
  • CSVは全件を書き出してから列で絞り込む
  • 同じ認証情報が複数の組織で使われると行が重複する
一覧を作っても認証情報は失効しません。不要な権限を見つけたら、利用中の処理への影響を確認して別途対処します。

〈知見〉Jevで読む記憶を絞る

今野健介氏が、検索済みの記憶候補をJevで選別してCodexやClaude Codeに渡す実装を紹介しました。「62.5%削減」は候補件数の上限を8件から3件に減らした場合の計算値で、総トークンや料金の削減実測ではありません。

キーポイント

  • ローカル検索を残し、その後に候補を選別
  • ダミーデータでの実通信で、2候補を1候補に絞れたと報告
  • 全体の費用効果は未測定で、Jev側にも処理が発生
試す際は必要な記憶が残っているかを確かめ、CodexやClaude Codeへ渡す文字数も記録しましょう。

〈知見〉Jevで意図から探すデモ

キーポイント
