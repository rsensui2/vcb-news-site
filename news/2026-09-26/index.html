Claudeが新しい酵素系ARTを発見。機能の解明はこれから

Anthropicの研究チームは、Claudeのエージェント群がDNA配列から未記載の酵素系ARTを見つけたと報告した。配列はCRISPRに似た反復を持つが、その働きはまだ分かっていない。人間の研究者が実験で検証を進めている。

キーポイント

  • 約950のエージェントが21時間、2億1000万トークンを使って探索した
  • 20万件超の逆転写酵素から3500件の候補を挙げ、詳しく調べる20件へ絞った
  • ARTは逆転写酵素、隣接する遺伝子、反復DNA配列からなる
  • 初期実験では反復配列が短いRNAとして発現した
AIによる大量の仮説探索と人間の実験検証を組み合わせた事例。発見の規模と、未解明の部分を分けて捉えたい。

GitHubの自動セキュリティ修正がCopilot Memoryを利用

GitHubのagentic autofixは、Copilot Memoryを有効にしている環境で既存の記憶を参照するようになった。修正後はパターンを記憶に残し、次の警告やほかのCopilot機能で再利用できる。両機能は公開プレビューだ。

キーポイント

  • セキュリティ警告への修正案を作る際にリポジトリの既存記憶を参照する
  • 作成した修正パターンを新しい記憶として保存する
  • 記憶はCopilot code reviewやcloud agentにも役立つ可能性がある
繰り返し起きる警告に、リポジトリ固有の修正知識を使える。Memoryの有効化状況と記録内容を確認したい。

SlackとTeamsのCopilotが会話の文脈をより多く利用

GitHub CopilotのSlack・Microsoft Teams連携で、会話中の添付ファイルや画像、転送メッセージなどを作業の文脈に使える範囲が広がった。Issue作成前の重複確認や、作業結果と元の会話を結ぶリンクも追加された。

キーポイント

  • Slackでは対応ファイル、添付、メッセージリンクを参照できる
  • Teamsではインライン画像、転送メッセージ、チャンネルとスレッド履歴を利用できる
  • Issue作成前に似たIssueを確認し、作成物へ直接リンクする
  • 次のメッセージからモデルを切り替え、その会話内で選択を維持する
チャットの決定をIssueや実装へ移す際、説明の転記を減らせる。公開プレビューの提供状況を確認して使いたい。

Turnstile Spin、AIエージェントがボット対策を実装

Cloudflareは、AIコーディングエージェントがTurnstileをサイトに組み込むTurnstile Spinを公開した。ウィジェットの設置だけでなく、バックエンドからSiteverifyへトークンを送って検証するところまで扱う。

キーポイント

  • Turnstileはサイト訪問者にパズルを解かせない仕組み
  • フロントエンドのウィジェットとバックエンドのSiteverify接続を一緒に実装する
  • 新規導入、検証漏れの修復、別のCAPTCHAからの移行を支援する
  • コード変更は開発者側のエージェントが行い、確認してから反映する
フォームへウィジェットだけ置き、サーバー側の検証を忘れる事故を減らせる。導入後は実際の送信経路まで試したい。

Cloudflare Containersの残存データ問題は修正済み

CloudflareはContainersとその上のSandboxesで、別テナントが以前使ったディスクの残存データを読める可能性があったと公表した。設定を修正し、古いディスクとスナップショットも退役させた。同社は悪用の証拠を確認していない。

キーポイント

  • 2026年9月4日にバグ報奨制度を通じて報告された
  • 薄いプロビジョニングに使うブロックのゼロ化が無効になっていた
  • 同社はゼロ化を戻し、旧ディスクとキャッシュ済みスナップショットを退役させた
  • 顧客側の設定変更は不要と案内している
共有コンテナの分離はアプリの認証だけで決まらない。ストレージの初期化設定も運用監査の対象になる。

GitHub Actionsの検索件数、2500件超は概数表示へ

GitHub Actionsの実行履歴を条件付きで検索した際、該当件数が2500件を超えるとAPIと画面に「2,500+」と表示される。大量検索がタイムアウトしたときに不正確な件数を返す問題への変更だ。

キーポイント

  • ワークフロー、イベント、状態、ブランチ、実行者による検索が対象
  • ページ分割された結果は従来どおり最大1000件を返す
  • 正確な総数が必要な連携は日付などで検索条件を絞る必要がある
CIの実行数をAPIで集計する仕組みは、件数フィールドを正確な総数として扱っていないか確認したい。

Cloudflare Imagesに画像変換の利用分析を追加

Cloudflare Imagesに、画像変換リクエストをアカウント単位で見る分析画面が加わった。URLによる変換とImagesバインディング経由の変換を分けて確認できる。表示値はサンプリングに基づく推定だ。

キーポイント

  • Images & StreamからTransformationsのAnalyticsを開く
  • URL変換では上位ゾーン、変換設定、オリジンホストを確認できる
  • Imagesバインディングでは利用の多いWorkerスクリプトを確認できる
画像変換の負荷や料金が偏っている場所を探しやすくなる。推定値なので厳密な請求件数とは区別したい。

コードだけでUIモーションを作る実装手順

zero氏は、Claude Opus 5.5を使って、一つのUI要素がボタンやスライダーなどへ連続変形する動画のプロンプトを公開した。HTMLで各時刻の状態を計算し、Playwrightとffmpegで描画する制作例だ。これは制作者の実例で、一般的な性能評価ではない。

キーポイント

  • 8〜12種類のUI状態を7小節の拍に合わせて配置する
  • seek(t)で状態を時間だけから計算し、タイマーやCSSトランジションに頼らない
  • Playwrightで1フレームにつき4枚を描き、ffmpegでモーションブラーを作る
  • 全編を描く前に各拍の静止画を確認する
AIへ映像を任せる際も、拍、状態遷移、検品フレームを先に指定すると手戻りを減らせる。
