Claude Sonnet 5.5は速度30%以上向上、タスク単価も低下

AnthropicはClaude Sonnet 5.5を公開した。Sonnet 5とトークン単価は同じだが、同社の検証では出力が30%以上速く、タスクあたりの費用は最大30%低い。GitHub Copilotも同日に提供を発表した。

キーポイント

  • 入力100万トークン2ドル、出力100万トークン10ドルでSonnet 5と同額
  • 範囲が明確な日常業務、バグ修正、文書・スライド作成を主用途に想定
  • GitHub CopilotのPro、Business、Enterpriseなどへ段階的に展開
日々の開発や資料作成では、難易度に応じてSonnet 5.5とOpus 5.5の仕上がりと費用を比べられる。速度と費用の数値はAnthropicの検証結果で、個々の作業では変わる。

Cloudflareの新CLI「cf」はAIエージェントの操作を広げる

Cloudflareは新しいコマンドラインツール「cf」のオープンベータを公開した。従来のWranglerが扱う約280のコマンド経路から、Cloudflare APIの3000超の操作を対象に広げる設計で、JSON出力を既定にした。

キーポイント

  • npm i -g cfでベータ版を導入
  • API定義からコマンドを生成し、エージェント向けのコマンド探索を備える
  • Workersから設定を始めるcloudflare.config.tsも導入
Cloudflareを使うAIエージェントの設定、配置、監視を一つの操作体系にまとめやすくなる。ベータ版のため、実運用前に使う機能を確認したい。

Vinext 1.0でNext.jsアプリの配置先が増える

CloudflareはViteベースでNext.jsの機能を再実装するVinext 1.0を発表した。App RouterとPages Routerの両方を対象とし、Cloudflare Workers、Netlify、AWS Lambdaなどへの配置を想定する。

キーポイント

  • npx vinext checkで既存アプリの移行可能性を確認
  • Cloudflareによると重要な機能の互換テストはキャッシュ関連を除き99%超
  • 自動テストにはNext.jsのエンドツーエンドテストも活用
既存のNext.jsアプリを動かす基盤を選び直せる。公開前には、使っている機能とキャッシュの動作を対象アプリで試す必要がある。

KitesurfがWebMCPに対応、サイトの機能を直接呼べる

CloudflareはWorkers上で動くブラウザKitesurfの更新を発表し、WebMCPへの対応を追加した。対応サイトが公開する操作を、AIエージェントがクリックの模倣を介さず呼び出せる。

キーポイント

  • Cloudflare Radarの公開プレイグラウンドでWebMCPの操作を試せる
  • JavaScriptとWasm DOMの往復を減らし属性参照を軽くした
  • Cloudflareの変更履歴にもWebMCP対応を記載
ブラウザを使うエージェントの操作経路が増えた。実際の成功率や速度は対象サイトごとの検証が必要だ。

GitHub、AI支援のAndroid監査で脆弱性24件を報告

GitHub Security Labは公開済みのTaskflow AgentをAndroidアプリ監査に使った手順を紹介した。対象を絞った調査フローと複数回の確認を組み合わせ、記事執筆時点で24件の脆弱性を発見・報告したとしている。

キーポイント

  • Taskflow Agentのコードと実行方法をGitHubで公開
  • AndroidのコンポーネントやIntentを調べる監査フローを設計
  • 記事では公開済みの脆弱性の具体例を2つ解説
AIによるセキュリティ監査は、調べる範囲と検証手順を明確にすると再現しやすい。24件はこの調査の結果であり、一般的な検出率ではない。

Microsoft、Blazor向けAgentic UI部品を試験公開
