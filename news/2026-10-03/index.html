Claude Codeの画面と動作をModsで拡張

Claude Code 2.1.287で、画面やツール呼び出しを変更できるClaude Modsが追加されました。作業の見落としを別エージェントが指摘する組み込みModも、Anthropicの直接提供セッションで、テレメトリーが有効な場合に使えます。

キーポイント

  • JavaScriptやTypeScriptの処理がClaude Code内で動く
  • 会話の横にパネルを出し、ツール呼び出しにも介入できる
  • Modsは利用者の権限で動くため、導入元と処理内容の確認が必要
作業状況の表示や独自の確認処理を、Claude Codeの画面に組み込めます。拡張コードが触れる範囲を把握してから試したい機能です。

npm、タグの切り替えも短期認証で自動化

npmのtrusted publishingで、バージョンを指すdist-tagを短期のOIDC認証で管理できるようになりました。公開後にlatestやbetaを切り替えるためだけに、長期トークンを残す必要が減ります。

キーポイント

  • Allow npm dist-tagは新規・既存とも初期状態で無効
  • タグ管理権限は直接公開の権限とは独立
  • npm CLIは11系で11.21.0以降、12系で12.2.0以降が必要
パッケージの公開とタグ変更を、CIの認証にまとめられます。公開済み版を切り替える処理があるチームは、権限設定を確認する価値があります。
