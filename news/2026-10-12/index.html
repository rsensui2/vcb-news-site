Ollama 0.40.3、モデルの裏側の移行を一時停止

Ollama 0.40.3は、ローカルモデルをバックグラウンドで移行する処理を一時停止しました。多数のリクエストを処理する用途で負荷が生じていたためで、ClaudeやCodexの起動時に表示される一部の警告もなくなります。

キーポイント

  • モデルのバックグラウンド移行を一時停止
  • 埋め込みなど大量リクエスト時の負荷が理由
  • Claude・Codexの起動時の一部警告を削除
ローカルAIで文書検索を動かしている人は、更新前後で埋め込み処理の時間を比較できます。高速化の幅は公表されていないため、手元のデータで確認しましょう。

Claude Code 2.1.296、委任先の会話を早めに圧縮

Claude Code 2.1.296で、委任先のサブエージェントが会話を自動圧縮するタイミングを設定できるようになりました。ワークフロー用エージェントのモデルを揃える設定も加わり、フォルダで無効にしたMCPサーバーが無人実行中に起動する不具合などを修正しています。

キーポイント

  • autoCompactWindowで委任先の圧縮タイミングを指定
  • ワークフロー用エージェントだけモデルを統一可能
  • 無人実行で無効なMCPサーバーが起動する不具合を修正
AIへ作業を分担させるとき、会話の長さと使用モデルを担当ごとに調整できます。MCPの修正は、無人実行でも接続先の設定を守るための変更です。

Codex 0.162.1、設定の差による起動失敗を修正

Codex 0.162.1は、動いているバックグラウンドサーバーとCLIの機能設定の差で起動に失敗する問題を修正しました。互換性の確認はコマンドラインで明示した上書きに限定され、複数行の質問で画面がクラッシュする問題も直しています。

キーポイント

  • サーバーとCLIの既定設定の差による起動失敗を修正
  • 互換性確認を明示的なコマンドライン指定に限定
  • 複数行の質問で起きる画面のクラッシュを修正
設定を変えていないのにCodexが起動できない場合、該当する修正か確認する材料になります。質問中の改行やリンクを保つ修正も入り、やり取りの途中で止まる問題に対処しています。

Liquid d1、画像の分類もAI Gatewayから

Vercel AI GatewayでLiquid AIの判断モデルd1が利用できるようになりました。文章や画像を用意した質問に照らし合わせ、分類・振り分け・採点の結果を確率とともに返します。自由な文章を生成する方式とは異なります。

キーポイント

  • モデル名liquid/d1で利用
  • 文章と画像を使った判断に対応
  • 選択肢・真偽・点数を構造化して返す
画像を指定カテゴリーへ分けるなど、答えの候補が決まった処理で試せます。AI Gatewayでは他のモデルと一緒に使用量と費用を確認できます。

〈知見〉動きの見本を使い、AIへの指示を具体化

MOTION MOVEMENT REFERENCEは、動きの名前・速さ・速度変化の曲線を手がかりに見本を探せるサイトです。再生速度を変えたりコマ送りしたりして動きを確認でき、比較用の画面では時間や振幅などを調整できます。新発表ではなく、制作に役立つ知見として紹介します。

キーポイント

  • 動きの名前・速さ・用途から見本を探せる
  • コマ送りで動きの途中を確認
  • 比較画面で時間・振幅・遅延を調整
AIに画面の動きを頼むとき、見本を選んで速さや止まり方を伝えると、依頼を具体的にできます。掲載の実装例は、作る画面の構造に合わせた調整が必要です。
