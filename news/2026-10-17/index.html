Beam、公開重みのAIを期間限定で無料提供

Vercelは、ステルス名Cat Jamで提供していたモデルの正体がReflection AIのBeamだと明らかにしました。AI Gatewayでは、Reflection AI経由の利用が公開記念の期間限定で無料になります。重みはApache 2.0で公開されています。

キーポイント

  • コード生成とエージェント作業向けの推論モデル
  • 100万トークンの文脈、ツール呼び出し、構造化出力に対応
  • 総501Bパラメータのうち、1トークンで23Bを使用
  • reflection/beamは無料期間後に有料へ移行
  • reflection/beam-freeは無料期間が終わると停止
既存のコーディングエージェントに入れて、品質や待ち時間を比較できます。自動課金を避けたい検証では、無料期間後に停止する名前を選ぶ方法があります。

Glimpse、画像や動画を見直しながら推論

Elorianは、考える途中で視覚情報を見直すモデルGlimpseを研究プレビューとして公開しました。画像や動画を処理するツール、コード実行、複数エージェントの協調を使い、APIとチャット画面から利用できます。公式記事の料金は100万トークンあたり入力0.60ドル、出力3ドルです。

キーポイント

  • 推論の途中で視覚情報を再確認
  • 画像変換・動画処理などのツールを利用
  • APIとチャット画面で研究プレビューを提供
  • 料金は入力0.60ドル・出力3ドル／100万トークン
  • 一部評価で上位モデル並みとする結果は自社評価
図表や動画の読み取りに使える候補が増えます。自社の資料で読み落としや誤認識を確認し、価格と精度を比較したいモデルです。

AI Search、日本語の自然文でキーワード検索

Cloudflare AI Searchのキーワード検索が、trigram設定で日本語・中国語・韓国語の質問に対応しました。従来は空白のない質問を一つの完全一致フレーズとして扱い、結果がほとんど返らないことがありました。設定を変更すると、文書全体の再インデックスが走ります。

キーポイント

  • 日本語・中国語・韓国語の自然文を検索可能
  • keyword_tokenizerをtrigramに設定
  • porterはこれらの言語に不向き
  • 空白なしの質問が完全一致扱いになる問題を改善
  • 設定変更時は全件再インデックス
社内規程に日本語で質問する検索システムを作りやすくなります。既存の運用では、設定変更後の再インデックスを見込んで切り替えます。

Claude Code、自動圧縮の切り替えを追加

Claude Code 2.1.302は、待機中の会話を自動圧縮するIdle compactionを、/configから切り替えられるようにしました。単体版Claude Designが12月14日までに終了する告知も追加されています。クラウドの定期ルーチンが途中失敗後に再実行され、同じ報告を投稿しうる不具合も修正しました。

キーポイント

  • /configでIdle compactionをオン・オフ
  • 単体版Claude Designは12月14日までに終了と告知
  • forkサブエージェントをSDKやVS Codeでも既定有効に
  • 同一イベントのフック同時実行を最大12個に制限
  • クラウドの定期ルーチンによる二重処理を修正
会話の自動整理を自分の運用に合わせて調整できます。定期実行を使う場合は、途中失敗後の重複処理を抑える修正にも注目です。

Copilot、3モデルの提供を11月16日に終了

GitHub Copilotは11月16日、Claude Opus 4.8、Claude Opus 5、GPT-5.6 Terraの提供を終了する予定です。推奨の代替はOpus 5.5、GPT-6.1 SolまたはGPT-6 Lunaです。年払いの個人契約では、Opus 4.8が引き続き利用できます。

キーポイント

  • 終了予定日は2026年11月16日
  • 対象はOpus 4.8・Opus 5・GPT-5.6 Terra
  • Opus系の代替はClaude Opus 5.5
  • Terraの代替はGPT-6.1 SolまたはGPT-6 Luna
  • 年払い個人契約のOpus 4.8は例外として継続
モデル名を固定している設定や連携は、期限までに見直す必要があります。組織のモデル利用ポリシーによっては、代替モデルを管理者が有効にする作業も必要です。

GitHub、依存ライセンスをマージ前に検査

GitHub Enterprise Cloudで、企業のライセンス方針に依存パッケージが合うかを検査する機能が一般提供されました。Code Securityを有効にしたリポジトリへルールを適用すると、依存を追加・変更するPRで検査します。エージェントがパッケージの準拠状況を問い合わせるAPIも用意されています。

キーポイント

  • Enterprise CloudのCode Security有効リポジトリが対象
  • 企業共通のライセンス方針をルールで適用
  • 依存を追加・変更するPRへ不適合を注記
  • 依存の置き換えや例外承認などで対処
  • 準拠確認APIをコーディングエージェントから利用可能
AIが追加するライブラリも、企業の利用方針に沿って確認できます。マージ時の検査に加え、導入候補を選ぶ段階でAPIを使う運用が考えられます。

yomiyasu、推敲後の数値や否定を検査

日本語推敲スキルyomiyasu v2.0.0は、書き直した文章を返す前に、数値や否定など原文の意味が保たれているかを検査します。相手や用途に合わせた表現と、Codexで名前を呼ぶだけで使う手順も改善しました。文章の読みやすさと内容の保持を合わせて確認する更新です。

キーポイント

  • 推敲後に数値や否定の変化を確認
  • 宛先や用途に合う言い回しへ調整
  • Codexで名前を呼ぶ操作を改善
  • v2.0.0のリリースノートを公開
メールや報告書の推敲では、流暢になっても金額や条件が変わると困ります。読みやすさを整えた後に内容も検査する手順を取り入れられます。
