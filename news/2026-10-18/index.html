DeepSeek更新版、性能と処理効率を改善

DeepSeekはV4.1 Flash 1017を公開し、前版より性能を高めながら処理時間と出力を減らしたと説明しています。重みも公開し、SearchとFetchのAPIを一般開放しました。各APIは1,000回0.75ドルで、対象ツール経由の無料利用は11月1日午前1時（日本時間）までです。

キーポイント

  • Web・アプリ・APIで更新版を提供
  • 自己フィードバックを使う強化学習で開発を改善
  • 重みをHugging FaceとModelScopeで公開
  • Search・Fetchは各1,000回0.75ドル
  • 対象ツール経由の無料利用は11月1日午前1時まで
エージェントの費用は単価だけでなく、完了までの時間と出力量でも変わります。自分の作業で前版と比べる判断材料になります。

Muse Spark Open、複数のMacで実行可能に

Metaは816Bパラメータ、稼働42Bの公開重みモデルMuse Spark Openを公開しました。AppleはM5 Ultra搭載Mac Studioを複数台つないだ実行結果を示し、4台・入力8,192トークンの条件で毎秒36.73トークンを記録しています。Mac1台で動くモデルではなく、商用利用には独自ライセンスの条件があります。

キーポイント

  • 総816B・稼働42Bの混合エキスパート型
  • 100万トークンの文脈と画像入力に対応
  • M5 Ultra搭載Mac Studioの複数台構成で実行
  • Appleの4台構成で毎秒36.73トークン
  • 商用条件付きのMuse Model License
情報を外へ送らずに大規模モデルを動かす構成が具体化しました。導入には複数台のメモリ容量と接続条件の確認が必要です。

FLUX 3 Image Klein、生成と編集を手元で

Black Forest Labsは5.6Bパラメータの画像モデルFLUX 3 Image Kleinの重みを公開しました。画像生成・編集・最大10枚の参照に対応し、枠の座標で配置や編集範囲を指定できます。公式はINT8版がVRAM 8GBのGPUでも動くと説明していますが、必要メモリは実行条件で変わります。

キーポイント

  • 生成・編集・最大10枚の参照画像に対応
  • 4K出力と座標の枠による配置指定
  • 高速な蒸留版と追加学習向けベース版
  • INT8版は公式説明でVRAM 8GBから
  • 年商500万ドル未満は条件付きで商用無料
画像の内容だけでなく置く場所まで指定できます。手元で使う場合はモデル形式、実行ソフト、商用ライセンスを合わせて確認しましょう。

〈知見〉Claudeと検証器で量子回路を改善

Anthropicらの研究は、Claudeが量子回路の案を作り、独立した評価プログラムが正しさと資源量を検査する反復手法を報告しました。8課題のうち7課題でゲート数と量子ビット数をともに削減し、残る課題では両者の交換条件を改善しています。量子計算機の実用化そのものを達成した研究ではありません。

キーポイント

  • 元論文は10月15日公開
  • 自然文の仕様から回路を提案
  • 外部評価器が正しさと資源量を採点
  • 8課題中7課題でゲート数と量子ビット数を削減
  • 残る課題ではゲート数とメモリの交換条件を改善
AIに任せる仕事では、成果を自動で検査する仕組みが反復の質を支えます。研究が示すのは、その設計を専門課題にも使える可能性です。

AI Gateway、会話ごとの費用とキャッシュを表示

Vercel AI GatewayのログにSessionsビューが加わり、会話ごとにエージェント名、費用、モデル、キャッシュ利用率を確認できます。各ターンを前回と同じ提供元へ送る経路も表示し、同一のsessionIdを渡して自分で会話をまとめられます。

キーポイント

  • Claude Code・Codex・Cursorなどを会話単位で表示
  • 費用・モデル・提供元・キャッシュ率を確認
  • ターンごとの所要時間と経路を追跡
  • 同じ提供元への振り分けでキャッシュを活用
  • sessionIdまたはx-session-idで会話を指定
費用が増えた会話を見つけ、入力の再利用が効いているかを調べやすくなります。モデル変更の前に作業単位の内訳を確認できます。

Workersの定期処理をローカルで手動テスト

Cloudflare WorkersのLocal Explorerから、scheduled()へCron Triggerを1回送れるようになりました。設定済みの式やその場で書いた式、指定した時刻で試せます。ブラウザで作った設定は本番に反映されず、ローカルではcronが自動実行されない点にも注意が必要です。

キーポイント

  • Local ExplorerでCron Triggersを選択
  • 設定済み・その場のcron式を実行
  • 実行時刻とnoRetry()の状態を確認
  • APIからも同じテストを実行可能
  • ローカルのテスト設定は本番へ反映されない
予定時刻を待たずに定期処理の動作を確かめられます。AIエージェントによる検証にも、手動と同じAPIを使えます。

Cloudflareの公式文書をCLIで検索

Cloudflare CLI 1.0.0-beta.16にcf docs searchが加わり、公式文書から最大5件をJSONで取得できます。AIエージェントは結果のURLからMarkdownの本文を読めます。同リリースではコマンド名をケバブケースに統一する互換性のない変更もあります。

キーポイント

  • cf docs searchで公式文書を検索
  • タイトル・説明・URLを最大5件のJSONで取得
  • 全文はMarkdownで取得可能
  • 検索にはインターネット接続が必要
  • getCreditsからget-creditsなど名称変更あり
AIに最新の仕様を読ませてから実装を頼めます。CLI更新時は、既存の自動化が呼ぶコマンド名も確認しましょう。
