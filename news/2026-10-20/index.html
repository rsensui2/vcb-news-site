Claude Code、再開時に利用枠の消費を警告

Claude Code 2.1.304は、放置していた会話の再開で5時間の利用枠を大きく使いそうな場合、Pro・Max利用者に警告を出します。プロジェクトと最近の会話を読み、auto modeに環境を教える対話式セットアップも加わりました。作業ツリー終了時にブランチを確認なく削除し、コミットを失う恐れがあった不具合も修正しています。

キーポイント

  • /auto-mode-setupで自動操作に使う環境を設定
  • 再開を続けるか、新しい会話を始めるか選べる
  • Bedrock・Vertex・Foundryなどでもセットアップ可能
  • --worktree終了時の無断削除を修正
長い会話を再開する前に、利用枠への影響を判断できます。自動操作を使う人は、環境設定と作業ツリーの修正も確認したい更新です。

Clairic、書類から型に沿った値を抽出

Cloudflareは、入力文と欲しい項目の型を渡すと、数値や日付などを返す抽出モデルClairicをWorkers AIでプレビュー公開しました。値が入力から決まらない場合に備え、nullの確率や信頼度も返します。入力100万トークンあたり0.10ドルで、出力トークンへの課金はありません。

キーポイント

  • 文字列・数値・日付・リストなどの型を指定
  • 各回答の信頼度とp_nullを確認できる
  • 画像は最大4枚まで入力可能
  • 形式が正しくても、内容の正しさは保証しない
  • 長い計算は入力を抽出してコード側で処理
請求書などから項目を取り出す業務で、自動処理と人の確認を分ける材料になります。信頼度の閾値は、自分の書類で精度を確かめて決めましょう。

Mercury 3、拡散方式の高速生成を提供

Vercel AI GatewayでInceptionのMercury 3が利用可能になりました。文章を並行して修正していく拡散方式を使い、100万トークンの文脈に対応します。Inceptionは毎秒1,000トークン超の生成速度を報告しており、提供開始時の料金は50%引きです。

キーポイント

  • モデル名はinception/mercury-3
  • ブラウザ操作や対話支援など、待ち時間の短さを重視
  • 100万トークンの文脈長
  • 速度は提供元の自己申告、割引終了日は記載なし
応答待ちが多いエージェントでは、速度と回答品質を一緒に比べる候補になります。公表速度が自分の用途でも出るかは、入力や接続先をそろえて確認が必要です。

Cloudflare MCP、必要な権限を後から追加

Cloudflare API MCPサーバーが段階的な認可に対応しました。最小限の権限で接続し、作業中に不足する権限があれば、対応クライアントが利用者へ追加の許可を求めます。すでに許可した権限は保持されます。

キーポイント

  • 接続時の同意画面でMinimalを選択
  • 不足した権限をinsufficient_scopeで通知
  • 段階的な認可に対応するクライアントが必要
AIに外部サービスを操作させる際、最初に渡す権限を絞れます。追加を求められたときも、その作業に必要な範囲か確かめて許可しましょう。

GitHub、未認証のcloneに一時的な制限

GitHubは異常なアクセスが多い期間、公開リポジトリへの未認証HTTPS clone・fetchの一部で、一時的に認証を求める場合があると案内しました。正当なアクセスも影響を受けることがあります。認証して再試行するか、保護が解除されてから再試行できます。

キーポイント

  • 認証済みHTTPS・SSH・pushは影響なし
  • Web閲覧やAPI通信も対象外
  • GitHub Actionsは組み込みのGITHUB_TOKENを推奨
  • 公開リポジトリ全般に認証を必須化する措置ではない
無人のCIやエージェントで突然cloneに失敗したら、認証が必要というエラーかを確認できます。自動取得では、適切な権限の認証をあらかじめ設定しておくと安定します。

〈知見〉Muse Glimmer、手元で動くエージェント設計

Metaは、手元の機械で動くエージェントを想定した30BモデルMuse Glimmerの技術レポートを公開しました。文章と画像を入力でき、約4ビットに量子化して1枚のGPUで動かす設計です。公式投稿でもMacやPCでの実用的な速度を説明しています。

キーポイント

  • 30Bは300億パラメータの規模
  • 100以上の言語のデータで学習
  • Apache 2.0ライセンスで公開
  • ツール利用や複数手順の計画に重点
  • 同規模モデルを上回るという評価はMetaの自己申告
クラウドに常時接続しないエージェントを検討する際の資料になります。モデルの新規発表として扱わず、手元の機械での速度や必要メモリを確認する材料として読みましょう。
