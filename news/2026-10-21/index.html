durable-harness、落ちた処理を記録から再開

Vercelは、AIエージェントの処理を記録し、中断後に続きから動かすdurable-harnessを公開しました。完了済みの呼び出しは記録を読み、途中だった道具の処理は再実行の方針に従って扱います。

キーポイント

  • Pi・OpenCode・Claude Code・Codexなどに対応
  • 完了したモデル呼び出しは再課金せず記録から復元
  • 道具ごとに再実行の可否を指定
  • Claude CodeとCodexはVercel Sandboxで動作
  • 自社Postgresなどへの保存にも対応
長時間の作業をAIに任せる際、停止後に何をやり直すかを設計できます。返金や投稿のような処理は、単に再試行するだけでは重複を防げない点が大切です。

DeepInfer、大規模推論の基盤を公開

DeepSeekは、DeepSeek-V4.1-Flashを動かす推論基盤DeepInferをオープンソースで公開しました。今回の公開範囲はオフライン推論で、完成した配信サービスをそのまま導入できるものではありません。

キーポイント

  • Apache 2.0ライセンスで公開
  • 対象はNVIDIA SM100とHuawei Ascend 950

  • 配信サービスにはKVキャッシュや負荷分散などが別途必要
自社で大規模モデルを運用するチームが、推論の仕組みを調べる材料になります。一般的なPCで手軽に動かすローカルAIアプリとは、必要な機材が違います。

OpenAI API、キャッシュを最低12時間保持

OpenAI APIで、共通の指示や資料を最低12時間キャッシュする設定が加わりました。GPT-5.6以降のResponses APIが対象で、書き込みは通常入力料金の2.5倍になります。

キーポイント

  • 既定の最低保持時間は30分
  • 12時間の設定はprompt_cache_options.ttlで指定
  • 30分の書き込みは通常入力料金の1.25倍
  • キャッシュの読み込み料金は保持時間によらず同じ
  • 12時間は削除期限ではなく最低保持時間
数時間おきに同じ資料を使う処理では、キャッシュを再利用しやすくなります。書き込みは割高なので、使う回数と読み込み量で費用を比較しましょう。

GitHub、npmの導入を検査するfirewall

GitHubは、npmパッケージを入れる際に危険な配布物を遮断するpackage firewallを公開プレビューにしました。GitHub Enterprise Cloud向けで、端末やAIエージェントの取得先をfirewallへ向ける設定が必要です。

キーポイント

  • 現時点はGitHub Enterprise Cloudのnpm向け
  • 公開直後の版に待機期間を設定
  • 悪意あるパッケージや脆弱性の情報で検査
  • プレビュー中は無料、一般提供後は従量課金予定
  • 遮断されたパッケージの例外申請も可能
AIにパッケージの導入まで任せる企業が、導入時の検査をまとめて適用できます。有効化するだけで全通信が保護されるわけではなく、各端末の接続設定も必要です。

Claude Code、Bedrock・Vertexの失敗を修正

Claude Code 2.1.305は、2.1.304で一部の接続先ですべてのリクエストが失敗する不具合を修正しました。ツール検索を受け付けないBedrock・Vertexやゲートウェイでは、ツール検索なしで再試行します。

キーポイント

  • ツール検索が拒否される環境で再試行
  • Workflow再開時の完了済みエージェントの再実行も修正
  • /usageに警告の原因と修正方法を表示
2.1.304への更新後に動かなくなった人は、接続先の条件を確認できます。昨日の更新案内に対する続報として、該当環境では修正版を検討したいところです。

Claude設計のタンパク質、17件で結合を確認

Anthropicは、研究用Claudeが設計したタンパク質を実験し、サソリの神経毒に結合する17件を確認したと報告しました。211件を調べた結果で、毒を無力化する作用や治療効果は未確認です。

キーポイント

  • 研究用モデルが約64時間の設計作業
  • 31万8,484候補から選び、人の追加分を含め211件を実験
  • Adaptyv BioとTwist Bioscienceが検証
  • 17件は4種類の毒のいずれかに結合
  • 全211件の設計とデータを公開
AIによる候補の設計を実験で確かめた研究例です。結合の確認から治療薬の開発までは、効果・安全性など多くの検証が残っています。

Vercel Functions、WebSocketを一般提供

Vercel FunctionsのWebSocket対応が一般提供になりました。接続を保ちながら双方向にやり取りでき、AIチャットや共同作業のアプリに使えます。

キーポイント

  • Vercel公表では1日1,500万接続を処理
  • 通常のFunctionsと同じ制限・料金体系
  • CPU料金はメッセージの処理時間に応じて発生
  • 関数の最大実行時間で切断するため再接続を実装
  • 永続データは外部の保存先で共有
リアルタイム通信をVercel上で作りやすくなります。接続が永久に続くわけではないので、再接続とデータの復元まで含めて組み立てましょう。

〈知見〉imozuru、引用をたどり原文を集める

imozuruは、知らない分野の用語や著者を調べ、引用やリンクをたどって原文を集めるClaude Codeのスキルです。主張ごとに原文の場所を示し、利用者が確かめられる形で結果を保存します。

キーポイント

  • 問いと必要な主張を先に整理
  • 用語・人物・知見が集まる場から探索
  • 原文を保存し、主張に対応する箇所を提示
  • 必要な根拠がそろうか、新資料が減ったら探索を終了
検索上位の要約だけでは判断しづらい調査で、原文を読む手がかりになります。検索語は外部へ送られるため、機密を含む問いの扱いには注意が必要です。
