PHPに重大な脆弱性、すぐ更新を

PHPの開発チームは、認証なしで外部からプログラムを実行される恐れがある重大な脆弱性2件を修正した、PHP 8.5.12、8.4.27、8.3.36、8.2.35を公開しました。Webのリクエストを処理するPHPはすべて対象で、特にApacheのmod_phpでは、アプリのコードが動く前に攻撃できることが確認されています。発見と公開前の調整には、AIを使ったセキュリティ企業やOpenAIが関わりました。

キーポイント

  • CVE-2026-109618（メモリ不足時の処理中断）とCVE-2026-109619（解放済みの状態が次のリクエストに残る）
  • 対象はPHP-FPM・mod_php・php-cgi・FrankenPHP・LiteSpeedなど、Webを処理する全構成
  • 8.1以前は公式更新なし。7.4・8.0・8.1向けに最小限のソース修正を特別に提供
  • Linuxディストリビューションには事前にパッチを配布済み
  • WizはWordPress・Drupal・Joomlaで認証なしのコード実行を実演
  • OpenAIは「Patch the Planet」として、保守者や研究者と公開前の準備を調整
WordPressなど、PHPで動くサイトを持つ人は今すぐ更新が必要です。アプリ側に欠陥がなくてもPHP本体から攻撃されるため、レンタルサーバーなら提供元の更新状況も確かめてください。

eMudhraの中間CA、秘密鍵が漏えい

インドの認証局eMudhraが発行した中間CA証明書8件で、秘密鍵の漏えいが判明しました。鍵の生成に欠陥があり、証明書から鍵を割り出せる状態だったため、この鍵があればどのサイトにもなりすませます。主要ブラウザとOSはすでに該当証明書を遮断しましたが、独自の証明書リストを持つ開発ツールやライブラリは、更新しないと信頼したままになります。

キーポイント

  • Firefox・Chromeは10月17日、Appleは19日、Microsoftは20日から遮断
  • 原因は認証局側の鍵生成の誤りで、2025年4月の作成時から鍵を割り出せた
  • Node.js 22.23.4、Python certifi 2026.10.19、Go 1.27.3、Claude Code 2.1.303 などが修正版
  • macOS標準のcurl・git・python3は古い証明書ファイルを参照するため、告知サイトに回避手順がある
  • 告知サイトのテストとcurlで、接続が拒否されれば安全
ブラウザだけ更新しても、サーバーやエージェントが使うランタイムの証明書リストが古いままだと偽のサイトを信じてしまいます。開発環境とサーバーの両方で、ランタイムと証明書パッケージの更新が必要です。

Claude Duet、先回りして動く秘書アプリ

Anthropicは、Claudeが自分から動くエージェントとして働く新しいアプリ「Claude Duet」の研究プレビューを始めました。毎朝、つないだアプリ全体から重要な項目をまとめて届け、日中は数時間おきに確認して、対応が必要なときだけ連絡してきます。メッセージの送信、支払い、署名、削除の前には、実行内容を見せて承認を待ちます。

キーポイント

  • iOS・Androidの単体アプリとclaude.aiで提供
  • まず米国のPro・Max加入者から、順番待ちリスト制
  • 利用上限は他のClaudeと共通で、裏での確認も消費する
  • 専用の仮想マシンとブラウザで動き、PCを閉じても作業を続ける
  • 証券の売買や口座間の送金は、承認があっても行わない
  • パスワードやログイン用のトークンを直接見ない設計
聞かれたら答えるAIから、状況を見て声をかけてくる秘書型のエージェントへ広がっています。日本ではまだ使えませんが、どこまで任せてどこで人が承認するかの線引きは、自社でエージェントを作るときの参考になります。

Claude API、新版でtemperature廃止

Anthropicは、Claude APIの新しいバージョン「2026-10-21」を公開しました。2023-06-01以来の新版で、Messages APIでは temperature・top_p・top_k を送ると、どのモデルでも400エラーになります。各言語のSDKとant CLIの新版はこの版を既定で送るため、SDKを上げるだけで既存のコードが止まる場合があります。

キーポイント

  • temperature・top_p・top_k は削除され、送ると400エラー
  • アシスタント側のメッセージに文書ブロックを直接入れると400エラー
  • Python SDK 2.0.0、TypeScript SDK 1.0.0、Go SDK 2.0.0 などが新版を既定で送る
  • 新しいSDKとant CLIのライセンスはMITからApache 2.0に変更
  • Admin APIでも項目名が変わる（roles → role_ids など）
  • Claude Platform on AWS・Microsoft Foundry・Google Cloudでも使える
依存関係の自動更新でSDKのメジャー版が上がると、temperature を指定しているコードがエラーになります。更新の前に移行ガイドを読み、パラメータを外しておく必要があります。

Claude Security、変更のたびに自動で再検査

Anthropicのセキュリティ診断ツールClaude Securityが、リポジトリをつなぐと最初に詳しく検査し、その後はコードの変更に合わせて継続的に再検査するようになりました。見つけた問題が直ると、Claude Code以外で修正した場合も自動で「修正済み」にし、再発すれば開き直します。Claude Enterprise向けのパブリックベータです。

キーポイント

  • GitHubアプリ（GitHub Enterprise Server含む）か、GitLabなどのアクセストークンで接続
  • プロジェクトごとに、デプロイ方法やセキュリティ方針を書く知識ベースを持てる
  • コードから脅威モデルを作り、重要度と攻撃経路の説明を付ける
  • API・Webhook・MCPコネクタから結果を扱える
  • 月2万5,000ドル分の無料クレジットを2か月（2026年12月31日までの利用）
  • 4月のベータ開始以降、100万件以上の脆弱性を発見（Anthropic発表）
AIがコードを大量に書くほど、たまに検査するだけでは追いつきません。変更のたびに自動で見張り、直ったかまで追う形は、セキュリティ確認の新しい標準になりそうです。

GitHub CLI、期限付きトークンを選択可能に

GitHub CLI（gh）で、有効期限付きで自動更新されるOAuthの認証情報を、パブリックプレビューとして選べるようになりました。v2.103.0以降で gh auth login --expiring を使うと、短命のアクセストークンを裏で自動更新するため、再ログインは不要です。トークンが漏れても、数時間で使えなくなります。

キーポイント

  • v2.103.0以降で gh auth login --expiring
  • 毎回使うなら gh config set expiring_credentials enabled
  • gitで使うなら gh auth setup-git と git 2.46以降を強く推奨
  • gh auth token の結果を保存して使い回すスクリプトは、期限切れで止まる
  • 今は任意だが、将来は新規ログインの既定にする予定
AIエージェントにghを使わせる場面が増え、トークンが漏れたときの被害を小さくする設定です。トークンを外の道具へ渡している自動化は、毎回 gh auth token で取り直す形に直しておく必要があります。

判定専用モデル、27日まで無料

Vercel AI Gatewayで、Basetenの判定専用モデルMammoth-1（27B）とElephant-1（9B）が10月27日まで無料で使えます。文章の分類、問い合わせの振り分け、指定した基準での採点に使うモデルで、選択肢・確率・スコアを返します。どの確率なら自動で処理し、どこから人の確認に回すかは、アプリ側で決めます。

キーポイント

  • 無料期間は10月27日まで
  • モデル名は baseten/mammoth-1 と baseten/elephant-1
  • コンテキストは16kトークン
  • 1回のリクエストで、窓口の選択・返金依頼か・緊急度などをまとめて聞ける
  • AI SDKの decide、Decisions API、TypeSafe互換の呼び方に対応
問い合わせの仕分けや承認の判断のように、選ぶだけの処理は大きなモデルでなくても回せます。確率付きで返るため、人に回す線を数字で決められます。
